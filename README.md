# КОМПАС.ЗАПИСКИ

Спокойное, быстрое приложение для заметок в Markdown. Локальные `.md`-файлы,
опциональное шифрование, синхронизация через своё хранилище бесплатно и через
облако КОМПАС по подписке.

**Android · Windows · Веб (PWA) — один и тот же функционал.**

---

## Что это за репозиторий

Монорепо всего продукта: ядро, редактор, дизайн-система, экраны, три
платформенные оболочки и облачный бэкенд.

```
packages/core     логика: vault, индекс, поиск, CRDT, крипто, синк, импорт/экспорт
packages/ui       токены (3 темы × 6 акцентов) и библиотека компонентов
packages/editor   CodeMirror 6 live-preview
packages/app      все экраны и всё поведение
apps/web          оболочка PWA
apps/desktop      оболочка Tauri 2 (Windows)
apps/mobile       оболочка Tauri 2 (Android)
server            KompasCloud API
deploy            nginx, Docker Compose, скрипты развёртывания
docs/spec         исходное ТЗ
docs/adr          архитектурные решения
```

Как именно строение репозитория гарантирует одинаковый функционал на всех трёх
платформах — в `docs/ARCHITECTURE.md` §1. Коротко: продуктового кода в `apps/*`
нет вообще, там только оболочки.

## Документы

| Файл | О чём |
| --- | --- |
| `docs/ARCHITECTURE.md` | Инженерный контракт: порты платформ, инварианты, перф-бюджеты |
| `docs/adr/` | Обоснование каждого отклонения от рекомендованного в ТЗ стека |
| `docs/spec/README.md` | Полное ТЗ: продукт, данные, синк, функции, этапы, DoD |
| `docs/spec/BEHAVIOR.md` | Поведение каждого элемента — **высший приоритет при расхождениях** |
| `docs/spec/SCREENS.md` | Поэкранная спецификация |
| `docs/spec/DESIGN_TOKENS.md` | Единственный источник цвета, типографики и метрик |
| `docs/spec/COMPONENTS.md` | Библиотека компонентов |
| `deploy/SETUP.md` | Что нужно сделать руками один раз при развёртывании |

Приоритет при конфликте документов: `BEHAVIOR.md` > `SCREENS.md` >
`DESIGN_TOKENS.md` > `README.md` (ТЗ) > `ARCHITECTURE.md`.

## Разработка

```bash
pnpm install
pnpm build          # собрать пакеты и веб
pnpm dev            # веб в режиме разработки
pnpm test           # тесты всех пакетов
pnpm typecheck
pnpm lint:tokens    # падает при hex-цвете вне токен-файла
```

## Продуктовые красные линии

Не реализуются никогда: базы данных и формулы · канбан · встроенный
календарь-планировщик · таск-менеджер с напоминаниями · сторонние плагины ·
геймификация · лента/соцсеть.

Инженерные инварианты (нарушение — блокирующий дефект на приёмке): file over
app · local-first · zero-knowledge · ни одного hex вне токенов · ни одной
строки, зашитой в компонент · ни одного SMS-зависимого пути · слова «Сохранить»
в интерфейсе нет · любой деструктив отменяем.
