# Концепция

## Продукт в одном абзаце

**ЗАПИСКИ** — спокойное, красивое, быстрое приложение для заметок в формате
Markdown. Локальные `.md`-файлы, опциональное шифрование, синхронизация
«которая просто работает»: бесплатно — через своё хранилище (WebDAV,
Яндекс.Диск, локальная папка), по подписке — через Облако Записок. Ориентиры по
духу — **Bear** (лаконичность, отсутствие трения) и **Obsidian** (владение
данными, открытый формат). **Не Notion**: никаких баз данных, таблиц-как-БД,
канбанов. Только заметки, сделанные идеально.

## Для кого

### Первичная аудитория: «беженцы» из Bear, Obsidian, Notion

Пользователь Android и/или Windows, который:

* хочет Bear, но не может — Bear существует только на устройствах Apple;
* устал от глючного мобильного клиента Obsidian и платного синка;
* устал от тяжести Notion и от того, что данные не его.

25–45 лет, пишет ежедневно: дневник, рабочие заметки, конспекты, черновики.

### Вторичная: помогающие специалисты

Личные профессиональные заметки, не привязанные к клиентам: конспекты
супервизий, обучения, статей, рефлексия. Это beachhead, а не потолок:
продукт **general-purpose**, аудитория шире — студенты, писатели,
разработчики, все, кто ушёл из Notion и Evernote.

Помогающие специалисты выбраны точкой входа по трём причинам: они много пишут,
ценят приватность и уже доверяют бренду КОМПАС.

## Пустая ниша

Из продуктового исследования (`ZAPISKI_Concept.md` §2.1):

| Продукт | Сила | Провал (жалобы пользователей) |
| --- | --- | --- |
| **Bear** | Лучший UX и дизайн в классе, markdown без трения | Только Apple. Нет Windows и Android. Синк только платный. Нет голосовых заметок. В вебе нет шифрования и экспорта |
| **Obsidian** | Открытые `.md`, владение данными, мощь | Android-версия годами глючит (клавиатура, символы, скролл). Конфликты синка. Синк платный. Хаос плагинов, ломающихся при обновлениях. Порог входа |
| **Notion** | Всё-в-одном | Медленный, перегруженный, данные не твои, оффлайн слабый |
| **Simplenote** | Бесплатный, везде | Только текст, нет медиа, нет полировки |

**Вывод:** в мире нет продукта «красота Bear + открытость Obsidian +
кроссплатформенность + честный бесплатный синк». В России — тем более: уход
западных сервисов, потребность в локальном хранении, 152-ФЗ.

### Как это превращается в решения

Каждая строка «провала» выше имеет прямое отражение в коде:

| Чужая боль | Наш ответ | Где это в коде |
| --- | --- | --- |
| Bear: только Apple | Один и тот же код ядра и редактора на всех целях | [ADR-0001](../adr/0001-yadro-na-typescript-vmesto-rust.md), порт `VaultStorage` |
| Bear: экспорт за paywall | Экспорт md / HTML / DOCX / PDF бесплатно | `packages/core/src/export/` |
| Bear: в вебе нет шифрования | Шифрование работает везде, включая веб (WebCrypto + Argon2id) | `packages/core/src/crypto/` |
| Obsidian: глючный Android-ввод | Live-preview никогда не прерывает композицию IME | [../dev/modules/editor.md](../dev/modules/editor.md#проблема-ime) |
| Obsidian: конфликты синка | CRDT + diff3, автослияние, обе версии в истории. Экрана «выберите файл» нет | `packages/core/src/sync/` |
| Obsidian: хаос вложений | Всегда относительные пути `attachments/…`, одна конвенция везде | `Vault.addAttachment` |
| Obsidian: хаос плагинов | Плагинов нет и не будет | [principles.md](principles.md) |
| Notion: данные не твои | `.md`-файлы на диске пользователя | Инвариант «file over app» |

## Чего продукт не делает

Красные линии, зафиксированные навсегда:

> базы данных и формулы · канбан-доски · встроенный календарь-планировщик ·
> таск-менеджер с напоминаниями · сторонние плагины · геймификация ·
> лента/соцсеть.

Обоснование каждой — в [principles.md](principles.md).

## Связь с экосистемой КОМПАС

ЗАПИСКИ — **самостоятельный B2C-продукт**. Связка с приложением практики
(приложение для психологов) существует, но она **опциональна и односторонняя**:
заметку можно привязать к карточке клиента через deep link.

Ни один экран ЗАПИСОК не должен требовать Дневника или выглядеть как его часть.
Единственное UI-проявление — деликатный чип в шапке заметки (`SCREENS.md`,
«Десктоп: три панели»).

Что даёт экосистема:

* общий дизайн-язык «спокойной рабочей среды» — бренд уже спроектирован;
* готовую GTM-машину: те же профессиональные сообщества, амбассадоры, вебинары;
* общий аккаунт (SSO), но **вход в ЗАПИСКИ никогда не требует Дневника**.

> ⏳ Чип связки с Дневником описан в `SCREENS.md` §4 как часть витринной
> заметки. В коде его нет: экран заметки собран, но deep link в Дневник на нём
> не появляется. Порт для перехода наружу (`openExternal`) готов во всех трёх
> оболочках — не хватает самого элемента.

**Bear для Android и Windows, у которого не ломается синхронизация.**
