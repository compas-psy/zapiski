# История изменений

Формат: обратный хронологический порядок, [Semantic Versioning](https://semver.org/lang/ru/).
Записи описывают то, что **реально есть в коде** на момент выпуска.

Разделы: **Добавлено** · **Изменено** · **Исправлено** · **Известные
ограничения**.

---

## 0.1.0 — август 2026

Первая внутренняя версия. Собраны все слои продукта: ядро, редактор,
дизайн-система, экраны, три платформенные оболочки и облачный бэкенд.
Приложение запускается — в вебе командой `pnpm dev`, на Windows и Android
сборкой из CI.

**Чего эта версия не значит.** Ни один клиентский артефакт ещё не собран и не
запущен: установщика Windows и APK не выпускали, релизных тегов не ставили,
развёртывания на сервер не было. Всё, что известно о качестве, известно из 695
автотестов и проверки типов.

### Добавлено

**Ядро (`@zapiski/core`)**

* Порты платформ: `VaultStorage`, `PlatformCapabilities`, `CryptoProvider`,
  `SyncBackend`, `NoteIndex`, `PdfRenderer` — единственное место, где платформы
  различаются.
* Vault: чтение и запись заметок, папки как реальные каталоги, закрепление,
  архив, корзина на 30 дней с восстановлением, вложения в `attachments/`
  с относительными путями, поиск неиспользуемых вложений.
* Атомарная запись (временный файл + `rename`) и **транзакционное
  переименование**: все входящие wiki-ссылки обновляются либо все, либо ни
  одной; незакрытый журнал откатывается при следующем открытии vault'а.
* Разбор markdown: заголовок как первая строка, теги (в том числе вложенные),
  wiki-ссылки с алиасами и якорями, признаки для оператора `has:`,
  опциональный YAML frontmatter, который сохраняется, но не требуется и не
  добавляется.
* Собственный инвертированный индекс и FTS: операторы `tag:`, `folder:`,
  `before:`, `after:`, `has:`, точные фразы в кавычках, исключения через минус,
  русские синонимы операторов и относительные даты; ранжирование «заголовок
  важнее тела», до трёх фрагментов с контекстом ±40 символов и готовыми
  диапазонами подсветки; backlinks.
* Шифрование: контейнер `.md.enc` (magic `ZPSK`), Argon2id по RFC 9106 +
  AES-256-GCM из WebCrypto, неэкспортируемый ключ, иерархия master → per-note,
  подсказка к паролю, задержки после неудачных попыток. Открытый текст на диск
  не пишется никогда, зашифрованные заметки не попадают в индекс.
* CRDT на Yjs: документ заметки, компактные логи, three-way merge, минимальные
  правки вместо «удалить всё и вставить».
* Синхронизация: движок с очередью, переживающей перезапуск; бэкенды
  «локальная папка», WebDAV, Яндекс.Диск (нативный REST + откат на WebDAV),
  облако КОМПАС; разрешение конфликтов CRDT → diff3 → обе версии в истории;
  локальная история на 50 снапшотов.
* Импорт: папка `.md` и Obsidian-vault как есть, Bear (`.bear2bk`), Notion
  (базы → markdown-таблицы), Evernote (`.enex`). Импорт никогда не
  перезаписывает существующие заметки.
* Экспорт: md-архив со структурой папок и вложениями, HTML, DOCX и PDF —
  бесплатно, без paywall. Печатный документ всегда светлый, колонка 640, без
  интерфейсных элементов; растеризацию делает движок печати платформы, поэтому
  кириллица печатается с нормальными шрифтами и переносами.
* Каталоги строк `ru` и `en`; раздел ошибок скопирован дословно из реестра
  `BEHAVIOR.md` §11.

**Редактор (`@zapiski/editor`)**

* Live-preview на CodeMirror 6: символы разметки всегда занимают своё место,
  меняется только прозрачность — **layout не сдвигается никогда**.
  `Decoration.replace` не используется ни разу.
* Защита ввода на мобильных клавиатурах: перерисовка откладывается до конца
  композиции IME, композиция отслеживается двумя независимыми способами.
* Расширения markdown: `==подсветка==`, `[[wiki-ссылки]]`, `#вложенные/теги`,
  сноски; GFM-таблицы и чекбоксы; подсветка кода для 24 языков с динамической
  загрузкой.
* Автодополнение тегов (по частоте использования) и заметок (fuzzy).
* Автоформатирование при вводе, поведение Enter/Tab/Backspace в списках,
  умная вставка HTML и картинок, вставка без форматирования.
* Поиск и замена внутри заметки со счётчиком «3 из 12».
* Режим фокуса, raw-режим, автосохранение (500 мс + blur), типографика из пяти
  настроек как множители над токенами.
* Полная карта хоткеев текста из `BEHAVIOR.md` §7, экспортируемая списком —
  чтобы палитра команд строилась из неё, а не из копии.

**Дизайн-система (`@zapiski/ui`)**

* Токен-слой: 3 темы × 6 акцентов, плотность и гарнитура, смена в рантайме без
  перезагрузки и без белой вспышки; размеры в `rem`.
* Библиотека компонентов: кнопки, поля, чипы, переключатели, строки списка со
  свайпами, оверлеи, тосты, скелетоны, дерево, diff, компоненты голосового
  режима.
* Витрина компонентов (`pnpm --filter @zapiski/ui gallery`).
* Self-hosted шрифты Golos Text, Source Serif 4, JetBrains Mono — без обращений
  к CDN в рантайме.
* Линтер `lint-tokens`: ни одного hex вне токен-файла.
* Контраст: все 90 пар из Definition of Done проходят порог 4.5:1. Три значения
  токенов, которые его не проходили, изменены по решению дизайнера — обоснование
  в брифе `docs/design/CONTRAST-BRIEF.md`.

**Экраны (`@zapiski/app`)**

* Все экраны спецификации `SCREENS.md`: онбординг из трёх шагов без
  регистрации, список заметок, редактор, библиотека, поиск, архив, корзина,
  настройки из восьми разделов, вход, paywall, мастер импорта, история версий,
  шифрование и разблокировка, лист приёма «Поделиться».
* Каркас из четырёх раскладок по брейкпоинтам 600 / 900 / 1200: один столбец,
  compact в альбомной ориентации, две панели, три панели.
* Палитра команд `Ctrl+K`: команды, заметки, папки, теги, настройки. Команды
  текста берутся из списка редактора, а не из копии, — поэтому список не может
  разойтись с хоткеями.
* Матрица «экран × состояние» из `BEHAVIOR.md` §12 и **отладочное меню**,
  которое рисует её кнопками: любая ячейка воспроизводима в один клик.
* Жесты: свайп в списке (порог 96 px; отпускание до порога не выполняет
  действие никогда), pull-to-search, долгое нажатие. Виртуализация списка от
  100 строк.
* Автозамок зашифрованной заметки по таймеру (по умолчанию 10 минут,
  настраивается) и разблокировка биометрией.

**Оболочки (`apps/*`)**

* **Веб (PWA):** `VaultStorage` поверх File System Access API с фолбэком на
  OPFS — заметки остаются обычными файлами в папке пользователя; биометрия
  через WebAuthn-PRF; печать в PDF через скрытый iframe; service worker, с
  которым приложение открывается без сети. Ответы `/api/*` не кэшируются
  никогда: очередь изменений ведёт ядро.
* **Windows (Tauri 2):** атомарная запись файла целиком внутри Rust,
  Windows Hello, глобальный хоткей `Ctrl+Alt+N`, трей с переключателем
  автозапуска, ассоциация `.md`, единственный экземпляр приложения, печать
  через WebView2, автообновление с проверкой подписи.
* **Android (Tauri 2 Mobile):** атомарная запись в Rust, Android Keystore +
  BiometricPrompt, настоящий `FLAG_SECURE`, share-target `ACTION_SEND`,
  деликатная хэптика, системная печать, свой апдейтер (встроенный апдейтер
  Tauri на Android не работает), сохранение файлов в «Загрузки» через
  MediaStore.

**Облако (`server`)**

* Zero-knowledge блоб-синк: манифест, чтение и запись блобов с `If-Match` и
  `If-None-Match`, мягкое удаление, адресация по содержимому.
* CRDT-апдейты (сервер их не интерпретирует), история версий с ретенцией 30 или
  365 дней, websocket мгновенного синка, отдающий только пути и идентификаторы.
* Аккаунты без паролей: Яндекс ID и magic-link (TTL 15 минут, одноразовый,
  привязан к устройству инициации). **Ни одного SMS-зависимого пути.**
* Подписка: пробный период 14 дней, ЮKassa с проверкой подписи вебхука,
  Google Play с серверной валидацией покупки, льготный период.
* Публикация по ссылке: HTML присылает клиент, сервер санирует по белому списку
  и отдаёт с CSP без скриптов.
* Фид автообновлений в формате Tauri updater.
* Квота 10 ГБ с учётом в той же транзакции, что и запись.
* Приватность: в логах нет ни содержимого, ни путей внутри vault'а.

**Инфраструктура**

* Развёртывание на `zapiski.cmpas.ru` рядом с работающим КОМПАС.Дневником:
  отдельный домен, порт 3100 на loopback, свой compose-проект, своя база, свои
  тома; nginx только добавляется, reload только при зелёном `nginx -t`.
  `notes.cmpas.ru` — псевдоним с постоянным редиректом на канонический домен.
* Пять workflow'ов: провижн, деплой, сборка Windows, сборка Android, проверки
  инфобеза. В preflight — типы, линт токенов, тесты, сборка, валидация compose
  и vhost. Проверки инфобеза отделены от деплоя, чтобы идти и на PR из форка.
* Аудит безопасности и модель угроз — `docs/dev/security/`.

### Известные ограничения

Перечислены честно, чтобы не выдавать незавершённое за готовое.

**Облако и аккаунт**

* **Клиент облака КОМПАС не подключится к серверу:** пути эндпоинтов в
  `@zapiski/core/sync` и в `server` разошлись. Приложение этот бэкенд даже не
  создаёт — кнопка «Облако КОМПАС» в настройках ведёт на paywall. Платных
  функций у пользователя фактически нет.
* **Вход не завершается.** Письмо magic-link отправляется, страница Яндекс ID
  открывается, но приём токена в оболочках не написан.
* **Яндекс.Диск как место хранения не подключается** — ему нужен тот же токен.
  Работают локальная папка и WebDAV.

**Платформы**

* **Виджеты Android, плитка Quick Settings и открытие `.md` из проводника
  Windows не доходят до приложения.** Оболочки доставляют событие до границы
  контракта; порты `takeInitialIntent`, `onIntent` и `publishWidgetSnapshot`
  объявлены, но ни одна оболочка их не отдаёт и приложение их не вызывает.
  Виджеты в этом состоянии показывают пустое, а не выдуманные заметки.
* **`FLAG_SECURE` есть только на Android.** У Windows и веба нет эквивалента —
  это ограничение платформ, а не недоделка; содержимое там защищает автозамок.
* **Ни один клиентский артефакт не собран:** установщика Windows и APK не
  выпускали, релизных тегов не ставили.
* **`pnpm-lock.yaml` не знает про `apps/mobile`** — `pnpm install
  --frozen-lockfile` в CI на этом откажется работать.

**Инфраструктура**

* **Healthcheck в `deploy/docker-compose.yml` указывает на `/api/v1/health`**,
  которого сервер не отдаёт (есть `/health`), — деплой в текущем виде упадёт по
  таймауту.
* **Развёртывания на сервер не было.**
* **Публикация заметки по ссылке** готова на сервере, но nginx не проксирует
  `/p/`, и клиента нет.

**Проверки**

* **Ввод на реальных Android-клавиатурах не проверялся** — требует устройств.
  Это риск-зона №1 из ТЗ.
* **Нет теста импорта на корпусе 1000+ заметок** — заявлен в приёмочном листе.
* **Витринная заметка** из `SCREENS.md` §4 нигде не собрана попиксельно.

**Функции**

* Tab-навигация по ячейкам таблицы и drag-перестановка элементов списка мышью
  не реализованы.
* Голос → Markdown, шаблоны, веб-клиппер, iOS и macOS — P1, не начаты.

Подробная сверка по каждой функции — [scope.md](scope.md), по этапам —
[roadmap.md](roadmap.md).
