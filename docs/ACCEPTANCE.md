# Приёмочный лист ЗАПИСКИ

Инструмент CPO. Каждый пункт — из ТЗ, со ссылкой на источник. Статусы:
**✅ выполнено** · **⚠️ частично** (с указанием, чего именно не хватает) ·
**❌ не выполнено** · **⛔ невозможно в текущей среде** (с указанием причины и
того, что нужно, чтобы стало возможно).

«Частично» без конкретики — недопустимый ответ. «Выполнено» без проверки —
тоже.

## D. Сквозной функционал (требование заказчика)

Главное требование: Android, Windows и веб — **одинаковый** функционал.

| # | Критерий | Как проверять |
| --- | --- | --- |
| D1 | В `apps/*` нет ни одного экрана и ни одной единицы продуктовой логики | Осмотр: в `apps/*/src` только точка входа, реализация портов, манифест |
| D2 | Все экраны живут в `packages/app` и монтируются всеми тремя оболочками | Сверка списка экранов |
| D3 | Отсутствующая на платформе возможность **скрыта**, а не показана выключенной | `BEHAVIOR.md` §5.1 |
| D4 | Автообновление работает на Windows и Android | Конфиг updater + фид `/api/v1/updates` |

## F. Красные линии продукта (`README.md` §1)

Не должно существовать: базы данных и формулы · канбан · встроенный
календарь-планировщик · таск-менеджер с напоминаниями · сторонние плагины ·
геймификация · лента/соцсеть.

Запрещено на paywall (`SCREENS.md` §9): таймеры обратного отсчёта ·
предвыбранный годовой тариф без явной пометки · скрытая кнопка закрытия ·
блокировка доступа к уже созданным заметкам.

## Что заведомо невозможно проверить в текущей среде

Фиксируется честно, чтобы не выдавать непроверенное за проверенное:

* Сборка и запуск на **реальном Android-устройстве** (нет Android SDK/NDK
  локально; сборка идёт на раннере GitHub Actions).
* Сборка **Windows-installer** (нет Windows-тулчейна локально; сборка идёт на
  раннере `windows-latest`).
* **Реальное развёртывание на сервер** — значения секретов `SERVER_HOST`,
  `SERVER_USER`, `SSH_PRIVATE_KEY` принципиально нечитаемы через API GitHub,
  поэтому SSH из этой сессии невозможен. Развёртывание выполняется workflow'ом
  после того, как владелец скопирует секреты в этот репозиторий.
* Регрессия ввода на **реальных клавиатурах** (Gboard, Яндекс.Клавиатура,
  SwiftKey) — требует физических устройств.
* **Контраст на OLED** — требует устройства.
