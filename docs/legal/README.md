# Документы для согласий

**ЧЕРНОВИК. Не публиковать без юридической проверки.**

Тексты лежат в `server/legal/` — образ API собирается с контекстом `server/`,
и всё, что вне его, в контейнер не попадает. Здесь — только эта записка.

Это тексты, на которые приложение просит согласие при регистрации.
Написаны они разработчиком, а не юристом, и служат ДВУМ вещам:

1. показать, какие именно сведения и для чего продукт собирает — это
   инженерный факт, и он здесь описан точно;
2. дать юристу заказчика готовую канву вместо чистого листа.

Юридические формулировки, реквизиты оператора, сроки хранения и порядок
обращений обязан выверить юрист. До этого момента страницы `/terms` и
`/privacy` отдают ровно этот текст с пометкой «черновик» наверху: показывать
человеку документ, который выглядит утверждённым, а таковым не является, —
хуже, чем показать честный черновик.

## Как заменить текст

1. Правите `server/legal/terms.md` и `server/legal/privacy.md`.
2. Меняете `LEGAL_VERSION` в `packages/core/src/legal.ts` на новую дату.
   Это обязательно: согласие даётся на конкретную редакцию, и после
   изменения текста прежнее согласие не является согласием на новый.
   Приложение спросит согласие заново при следующем входе.
3. Убираете `DRAFT = true` в `server/src/routes/legal.ts`, когда текст
   выверен.
