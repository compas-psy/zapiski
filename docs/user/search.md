# Поиск

Поиск идёт по всему тексту заметок и работает мгновенно — даже когда заметок
десять тысяч. Интернет для него не нужен: указатель хранится на устройстве.

> ⏳ Экран поиска ещё собирается. Сам поиск и все условия, описанные ниже, уже
> работают.

## Как искать

Начните печатать — результаты обновляются по мере набора. Совпадения
подсвечиваются прямо в найденных строчках, показывается до трёх фрагментов из
каждой заметки с окружающим текстом.

Порядок результатов: сначала те, где совпадение в заголовке, потом — где в
тексте. При равенстве выше окажется то, что вы правили недавно.

Поиск не различает заглавные и строчные буквы, а «ё» и «е» считает одной
буквой: `елка` найдёт и «ёлку».

Пустая строка поиска показывает недавние запросы и последние открытые заметки.

## Условия поиска

Чтобы сузить поиск, к словам можно добавить условия. Условия можно
комбинировать в любом порядке — они складываются.

| Условие | Что означает | Пример |
| --- | --- | --- |
| `tag:` | Только с этим тегом | `tag:практика` |
| `folder:` | Только в этой папке | `folder:Личное` |
| `before:` | Изменено раньше даты | `before:2026-08-01` |
| `after:` | Изменено начиная с даты | `after:вчера` |
| `has:image` | Есть картинка | `has:image` |
| `has:file` | Есть вложенный файл | `has:file` |
| `has:todo` | Есть список задач | `has:todo` |
| `has:link` | Есть ссылка | `has:link` |
| `"…"` | Точная фраза целиком | `"план на осень"` |
| `-` | Исключить слово | `-черновик` |

Можно писать и по-русски: `тег:`, `папка:`, `до:`, `после:`, `есть:` работают
так же.

### Даты

В `before:` и `after:` понимаются:

* полная дата — `2026-08-01`;
* месяц — `2026-08`;
* год — `2026`;
* слова: `сегодня`, `вчера`, `неделя`, `месяц`, `год`.

### Примеры

```
супервизия tag:практика
```
Заметки со словом «супервизия», у которых есть тег `#практика`.

```
tag:работа after:неделя
```
Всё по работе, что вы трогали за последнюю неделю.

```
"годовой отчёт" folder:Проекты -черновик
```
Точная фраза «годовой отчёт» в папке «Проекты», кроме тех, где встречается
слово «черновик».

```
has:todo tag:дом
```
Домашние заметки, в которых остались невыполненные списки.

```
встреча before:2026-01-01
```
Заметки про встречи, которых вы не касались с начала года.

## Вложенные теги

Тег `#практика` найдёт и заметки с `#практика/супервизия`, и с
`#практика/группа`. Чтобы найти только конкретный, укажите его целиком:
`tag:практика/супервизия`.

## Чипы-фильтры

Над результатами есть готовые фильтры — тег, папка, период, тип содержимого.
Нажатие по фильтру дописывает соответствующее условие в строку поиска, снятие —
убирает. Строка и фильтры всегда показывают одно и то же: можно пользоваться
любым способом, как удобнее.

## Зашифрованные заметки

Содержимое зашифрованных заметок не ищется — приложение его просто не видит,
пока вы не введёте пароль. Такие заметки появятся в конце списка результатов,
только если совпало их название, с пометкой «зашифровано — содержимое не
ищется». Это не ограничение, а следствие того, как устроено шифрование:
[подробнее](encryption.md).

## Если ничего не нашлось

Приложение покажет «Ничего не нашлось» и перечислит условия, которые сейчас
активны, — чтобы можно было снять лишнее. Никаких абстрактных «попробуйте
иначе».

Частые причины:

* опечатка в слове;
* активен фильтр по папке или тегу, а нужная заметка лежит в другом месте;
* заметка зашифрована — её текст не ищется;
* заметка в архиве и вы смотрите только основной список.

## Поиск внутри открытой заметки

`Ctrl+F` — узкая строка поиска поверх текста со счётчиком «3 из 12».
Enter и Shift+Enter — переходы между совпадениями, `Esc` — закрыть, вернувшись
на то место, где вы были. `Ctrl+H` добавляет строку замены.

## Что ссылается на эту заметку

Внизу заметки есть панель «Ссылаются на эту заметку» — список записей, в
которых стоит ссылка на текущую. Если ссылок нет, панели просто не будет —
пустого «0 ссылок» вы не увидите. ⏳
