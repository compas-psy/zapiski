# Горячие клавиши и жесты

На macOS вместо Ctrl используется Cmd.

Значок ⏳ означает, что сочетание предусмотрено, но в текущей сборке ещё не
работает.

## Работа с заметками

| Сочетание | Действие |
| --- | --- |
| `Ctrl+N` | Новая заметка |
| `Ctrl+Shift+N` | Новая заметка в текущей папке |
| `Ctrl+Shift+P` | Закрепить или открепить |
| `Ctrl+Shift+E` | Экспортировать заметку |
| `Ctrl+,` | Настройки |
| `Ctrl+Alt+N` | Быстрая заметка поверх всех окон (только Windows, сочетание настраивается) |

## Навигация и поиск

| Сочетание | Действие |
| --- | --- |
| `Ctrl+K` или `Ctrl+P` | Палитра команд |
| `Ctrl+Shift+S` | Поиск по всем заметкам |
| `Ctrl+\` | Показать или скрыть боковую панель |
| `Ctrl+F` | Поиск внутри заметки |
| `Ctrl+H` | Замена внутри заметки |
| `Esc` | Выйти из режима фокуса, поиска или палитры |

## Оформление текста

| Сочетание | Действие |
| --- | --- |
| `Ctrl+B` | Жирный |
| `Ctrl+I` | Курсив |
| `Ctrl+U` | Подсветка `==текст==` |
| `Ctrl+Shift+X` | Зачёркнутый |
| `Ctrl+1` … `Ctrl+6` | Заголовок первого–шестого уровня |
| `Ctrl+0` | Обычный абзац |
| `Ctrl+Shift+L` | Маркированный список |
| `Ctrl+Shift+O` | Нумерованный список |
| `Ctrl+Shift+K` | Список задач |
| `Ctrl+Shift+Q` | Цитата |
| `Ctrl+Shift+C` | Блок кода |
| `Ctrl+L` | Вставить ссылку |
| `Ctrl+Shift+W` | Ссылка на другую заметку |

## Правка

| Сочетание | Действие |
| --- | --- |
| `Ctrl+D` | Продублировать строку |
| `Alt+↑` / `Alt+↓` | Переместить строку вверх или вниз |
| `Ctrl+Enter` | Отметить задачу на строке с курсором |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / вернуть |
| `Ctrl+Shift+V` | Вставить без оформления |
| `Enter` в списке | Следующий пункт; на пустом пункте — выйти из списка |
| `Tab` / `Shift+Tab` в списке | Вложить пункт / вернуть на уровень выше |
| `Backspace` в начале пункта | Убрать маркер, не удаляя строку |

⏳ Переставлять пункты списка мышью пока нельзя — только `Alt+↑` и `Alt+↓`.
Переходить по ячейкам таблицы клавишей `Tab` тоже пока нельзя.

## Вид

| Сочетание | Действие |
| --- | --- |
| `Ctrl+E` | Исходный текст ↔ обычный вид |
| `Ctrl+Shift+F` | Режим фокуса |

## Палитра команд

`Ctrl+K` открывает строку, в которой можно найти что угодно:

| Что ввести | Что найдётся |
| --- | --- |
| просто текст | команды и заметки |
| `/` | папки |
| `#` | теги |
| `>` | настройки |

Показывается до восьми результатов, стрелки водят по списку, Enter выбирает,
`Esc` закрывает. Рядом с командой видно её сочетание клавиш. При пустом запросе
сверху — три последние использованные команды.

## Жесты на телефоне

| Жест | Действие |
| --- | --- |
| Свайп от левого края | Открыть боковую панель; в заметке — вернуться к списку |
| Свайп по строке вправо | Закрепить или открепить |
| Свайп по строке влево | В архив |
| Потянуть список вниз | Открыть поиск |
| Потянуть список вниз двумя пальцами | Синхронизировать сейчас |
| Долгое нажатие по строке | Меню действий с заметкой |
| Долгое нажатие по ссылке | Предпросмотр |
| Двойное нажатие по слову | Выделить слово |
| Свайп вниз при просмотре фото | Закрыть просмотр |

Свайп можно передумать: пока строка не сдвинута примерно на треть экрана,
отпускание вернёт её на место и ничего не произойдёт. Когда порог пройден,
телефон коротко откликнется вибрацией — вибрация есть только на Android.

## Панель над клавиатурой

Первая строка: заголовок · жирный · курсив · список · задача · фото ·
микрофон · «⋯».

Кнопка «⋯» открывает вторую строку: цитата · код · таблица · разделитель ·
ссылка · сноска · ссылка на заметку.

Кнопка «H» переключает уровень заголовка по кругу: первый → второй → третий →
обычный текст.

⏳ Кнопки «фото» и «микрофон» пока ничего не делают: выбор картинки из галереи
и голосовые заметки появятся позже. Картинку можно вставить из буфера обмена —
это работает.
