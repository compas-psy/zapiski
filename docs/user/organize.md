# Порядок в заметках

Два способа разложить записи по местам — папки и теги. Они не заменяют друг
друга, и пользоваться можно обоими сразу.

## Папки

Папки в приложении — это настоящие папки на диске. Создали «Проекты» —
на диске появилась папка «Проекты», и заметки из неё лежат внутри неё же.
Открыв папку с заметками в проводнике, вы увидите ровно ту структуру, которую
построили в приложении.

Что можно делать с папкой (долгое нажатие по ней в боковой панели):

* создать вложенную папку;
* переименовать;
* переместить;
* удалить.

**Удаление папки — единственное место, где приложение переспрашивает**, потому
что вариантов два: удалить только папку, а заметки поднять на уровень выше,
или удалить папку вместе с заметками (тогда они уйдут в корзину).

Рядом с названием папки — счётчик заметок внутри, включая вложенные папки.
Архивные в счётчик не входят.

## Теги

Тег — это слово со знаком `#` прямо в тексте заметки:

```markdown
Конспект встречи #работа #клиенты/иванов
```

Чем теги отличаются от папок: заметка лежит **в одной** папке, но может иметь
**сколько угодно** тегов. Папка — это где заметка хранится, тег — про что она.

Теги бывают вложенными через косую черту: `#клиенты/иванов`. В боковой панели
они показываются деревом, а поиск по `#клиенты` найдёт и все вложенные.

Дерево тегов строится из текстов заметок, поэтому напрямую его не
редактируют. Но тег можно **переименовать** (долгое нажатие → «Переименовать»)
— приложение заменит его во всех заметках сразу и покажет, в скольких. Это
действие можно отменить.

Удалить тег из заметки просто: сотрите его из текста.

## Закрепление

Закреплённые заметки всегда наверху списка, в отдельном разделе. Закрепить или
открепить можно свайпом вправо или через меню по долгому нажатию.

## Архив

Архив — для того, что уже не нужно каждый день, но выбрасывать жалко.
Заметка из архива исчезает из основного списка, но остаётся в поиске и никуда
не девается с диска.

Отправить в архив — свайп влево. Сразу после этого внизу появится сообщение
«Заметка в архиве» с кнопкой «Отменить»: у вас есть шесть секунд, чтобы
передумать.

Вернуть из архива — открыть раздел «Архив» и сделать свайп влево ещё раз.

## Корзина

Удалённые заметки попадают в корзину и лежат там **30 дней**. Всё это время их
можно вернуть на прежнее место.

Сразу после удаления внизу появляется «Заметка в корзине · Отменить» — шесть
секунд, чтобы вернуть одним нажатием.

Корзину можно очистить вручную: раздел «Корзина» → «Очистить». Это одно из трёх
мест, где приложение переспрашивает, потому что отменить очистку уже нельзя.

По истечении 30 дней заметки удаляются сами.

## Сортировка

В меню «⋯» в шапке списка: по дате изменения (обычный порядок), по дате
создания, по заголовку А-Я или вручную. Выбор запоминается **для каждой папки
отдельно** — в рабочей папке может быть один порядок, в дневнике другой.

Заметки группируются по месяцам: «АВГУСТ», «ИЮЛЬ», а за прошлые годы —
«АВГУСТ 2025».

## Жесты на телефоне

| Жест | Что делает |
| --- | --- |
| Свайп по строке вправо | Закрепить или открепить |
| Свайп по строке влево | В архив (в архиве — вернуть обратно) |
| Долгое нажатие по строке | Меню: закрепить, дублировать, переместить, зашифровать, экспорт, в архив, удалить |
| Потянуть список вниз | Открыть поиск |
| Потянуть список вниз двумя пальцами | Синхронизировать сейчас |
| Свайп от левого края | Открыть боковую панель с папками и тегами |

Свайп можно передумать: пока вы не дотянули строку примерно до трети экрана,
отпускание просто вернёт её на место, и ничего не произойдёт. Когда порог
пройден, телефон коротко откликнется вибрацией — на Android; на компьютере и в
браузере вибрации нет, потому что вибрировать там нечему.

У зашифрованной заметки свайпы работают как обычно — закрепить и отправить в
архив можно, не вводя пароль. А вот «Экспорт» и «Дублировать» в меню не
появятся: для них нужно сначала открыть заметку.

## Что происходит с файлами

Все эти действия — обычные операции с файлами:

* переместили заметку в папку — файл переехал в соседний каталог;
* переименовали заметку — файл переименовался, а **все ссылки на неё из других
  заметок обновились сами**. Приложение сообщит, сколько ссылок поправило;
* удалили — файл переехал в служебную папку `.zapiski/trash`;
* архивировали — файл остался на месте, изменилась только пометка.

Никаких скрытых баз данных: то, что вы видите в приложении, лежит на диске
ровно так же.
