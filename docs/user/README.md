# Справка КОМПАС.ЗАПИСКИ

Спокойное приложение для заметок. Ваши записи — обычные текстовые файлы на
вашем устройстве. Их можно зашифровать, синхронизировать между телефоном и
компьютером и в любой момент открыть чем угодно ещё.

> **О состоянии этой справки.** Сейчас идёт версия 0.1.0: готова внутренняя
> часть приложения, а экраны ещё собираются. Справка описывает то, как продукт
> устроен и как он будет работать, и честно помечает значком ⏳ всё, что пока
> недоступно. Ничего выдуманного здесь нет: если раздел помечен ⏳ — значит,
> этой возможностью нельзя воспользоваться сегодня, и мы говорим об этом прямо,
> а не умалчиваем.

## Главное в трёх строках

1. **Заметки — это файлы.** Обычные `.md` в папке, которую выбрали вы.
   Приложение можно удалить — записи останутся.
2. **Сохранять ничего не надо.** Кнопки «Сохранить» в приложении нет: всё
   записывается само.
3. **Интернет не нужен.** Приложение полностью работает без сети и без
   регистрации. Синхронизация — дополнение, а не условие.
