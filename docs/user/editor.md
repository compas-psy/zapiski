# Как писать

Заметки пишутся обычным текстом. Чтобы что-то выделить или сделать список,
используются несколько простых значков — это называется Markdown. Их не нужно
запоминать все сразу: почти всё можно поставить кнопками на панели внизу
(на телефоне) или горячими клавишами (на компьютере).

## Два правила, которые стоит знать сразу

**Заголовок — это первая строка.** Отдельного поля для названия нет. Что вы
написали первой строкой, то и станет названием заметки в списке и именем файла
на диске. Если начать её со знака `#`, она ещё и оформится как крупный
заголовок.

**Сохранять ничего не надо.** Кнопки «Сохранить» в приложении нет. Текст
записывается сам — примерно через полсекунды после того, как вы перестали
печатать, и обязательно в момент, когда вы уходите с заметки, сворачиваете
приложение или закрываете его.

## Разметка

### Заголовки

Поставьте в начале строки решётки и пробел. Чем больше решёток — тем мельче
заголовок.

```markdown
# Самый крупный заголовок
## Заголовок раздела
### Подраздел
```

Заголовки отличаются размером и насыщенностью, а не цветом.

### Выделение внутри текста

| Что напечатать | Что получится |
| --- | --- |
| `**важное**` | **важное** — жирный |
| `*мысль*` | *мысль* — курсив |
| `~~отменилось~~` | зачёркнутый |
| `==главное==` | текст на цветной подложке |
| `` `команда` `` | моноширинный текст, как в коде |

### Списки

```markdown
- первый пункт
- второй пункт

1. по порядку
2. и дальше
```

Нажмите Enter — появится следующий пункт того же вида. Нажмите Enter на пустом
пункте — список закончится. Tab делает пункт вложенным, Shift+Tab возвращает
обратно (до шести уровней).

### Списки задач

```markdown
- [ ] позвонить в клинику
- [x] отправить договор
```

Квадратик нажимается прямо в тексте: одно касание — задача отмечена, текст
уходит в серый и зачёркивается. Нажатие по самому тексту просто ставит курсор,
не отмечая задачу.

Отмеченные задачи остаются на своих местах и никуда не уезжают.

Быстрый способ: напечатайте `[] ` в начале строки — приложение само превратит
это в квадратик.

### Цитаты

```markdown
> Мы не можем решить проблему тем же мышлением, которое её создало.
```

Слева появится тонкая линия, текст станет курсивным.

### Таблицы

```markdown
| Клиент | Встреча | Статус     |
| ------ | ------- | ---------- |
| Марина | 12 мая  | состоялась |
| Артём  | 14 мая  | перенесена |
```

Это простые таблицы для наглядности, а не база данных: считать в них ничего не
нужно и нельзя.

⏳ Переходить между ячейками клавишей Tab пока нельзя — таблица правится как
обычный текст.

### Код

Три обратные кавычки, название языка, Enter — приложение само закроет блок и
поставит курсор внутрь:

````markdown
```python
def hello():
    print("привет")
```
````

Подсветка работает примерно для двадцати языков и меняется вместе с темой
оформления.

### Разделитель

Три дефиса на отдельной строке и Enter — получится горизонтальная черта.

### Сноски

```markdown
Основной текст[^1]

[^1]: Пояснение внизу заметки.
```

## Теги

Напишите `#` и слово прямо в тексте — это тег:

```markdown
Разобрать конспект #супервизия #практика/группа
```

* После `#` и первой буквы появляется подсказка с тегами, которые вы уже
  использовали. Чем чаще вы им пользуетесь, тем выше он в списке.
* Теги могут быть вложенными: `#практика/группа`. Тогда поиск по `#практика`
  найдёт и его тоже.
* Пробел завершает тег.
* Нажатие по тегу в тексте открывает поиск по этому тегу.

Теги живут прямо в тексте заметки — значит, они сохранятся, даже если открыть
файл в другом редакторе. В шапке заметки они дополнительно показаны чипами:
нажатие по чипу открывает список заметок с этим тегом.

## Ссылки на другие заметки

Напечатайте две квадратные скобки `[[` — откроется список ваших заметок,
выбирайте нужную.

```markdown
Продолжение мысли из [[Идея продукта]].
Ссылка с другой подписью: [[Идея продукта|той самой идеи]].
```

Нажатие по такой ссылке открывает заметку. Если заметки с таким названием ещё
нет, ссылка будет нарисована пунктиром — нажмите на неё, и приложение
предложит создать заметку с этим названием.

Обычные ссылки на сайты пишутся так:

```markdown
[название](https://example.com)
```

Если вставить ссылку, когда выделен текст, она обернёт выделенное — получится
`[выделенный текст](адрес)`.

## Картинки

Три способа:

1. **Вставить из буфера обмена** — приложение само положит картинку в папку
   `attachments` рядом с заметками и подставит ссылку на неё.
2. **Написать вручную**: `![](attachments/имя-файла.png)`.
3. ⏳ **Кнопка с фотографией** на панели над клавиатурой — выбрать из галереи
   или снять камерой. Кнопка есть, но пока не работает.

Картинка показывается прямо в тексте. Пути всегда относительные — это значит,
что папку с заметками можно перенести куда угодно, и картинки не потеряются.

Если удалить ссылку на картинку из текста, сам файл останется в `attachments`.
Найти такие «осиротевшие» файлы можно в настройках, в разделе «Хранилище».

## Как выглядит разметка при письме

Значки разметки (`#`, `**`, `>` и другие) не мешают читать: они почти
прозрачны, пока курсор от них далеко, и мягко проявляются, когда вы подводите
курсор к строке.

Важная деталь: **текст при этом не сдвигается ни на пиксель**. Значки всегда
занимают своё место, меняется только их видимость. Это сделано специально —
скачущий текст мешает писать.

Если хочется видеть весь текст «как есть», со всеми значками, нажмите
`Ctrl+E` — это режим исходного текста. Повторное нажатие возвращает обычный
вид.

## Режим фокуса

`Ctrl+Shift+F` скрывает всё лишнее и приглушает все абзацы, кроме того, в
котором стоит курсор. Выход — `Esc`.

## Панель над клавиатурой

На телефоне над клавиатурой есть строка кнопок: заголовок, жирный, курсив,
список, задача, фото, микрофон и «⋯». Последняя кнопка открывает вторую
строку: цитата, код, таблица, разделитель, ссылка, сноска, ссылка на заметку.

Кнопка «H» переключает уровень заголовка по кругу: H1 → H2 → H3 → обычный
текст.

Если ничего не выделено, кнопки «жирный» и «курсив» ставят пару значков и
помещают курсор между ними — можно сразу печатать.

⏳ Кнопки «фото» и «микрофон» на панели пока ничего не делают: выбор картинки
из галереи и голосовые заметки появятся позже.

## Поиск внутри заметки

`Ctrl+F` открывает узкую строку поиска с счётчиком вроде «3 из 12». Enter —
к следующему совпадению, Shift+Enter — к предыдущему, `Esc` — закрыть.
`Ctrl+H` добавляет строку замены.

## Что ещё полезно знать

* **Отменить** — `Ctrl+Z`, вернуть — `Ctrl+Y`. История отмены живёт, пока
  открыта заметка.
* **Вставить без оформления** — `Ctrl+Shift+V`. Обычная вставка из браузера
  сохраняет заголовки, списки и жирный шрифт, превращая их в разметку.
* **Переместить строку** — `Alt+↑` и `Alt+↓`. **Продублировать** — `Ctrl+D`.
* Полный список — [горячие клавиши и жесты](shortcuts.md).
