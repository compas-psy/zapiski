# ЗАПИСКИ · Импорт — спецификация к реализации

Статус: **обязательна к исполнению**. Отрисовка — «ЗАПИСКИ Дизайн.dc.html», ход 6 (`#6a`…`#6i`).
Правила поведения общего продукта — `BEHAVIOR.md` §9. Токены — `zapiski.css`.

Промо обещает: «Импорт из Obsidian, Bear, Notion и Evernote — со вложениями и ссылками».
Эта спецификация закрывает обещание **четырьмя экранами и одной шторкой**, без отдельного визарда на каждый источник.

## 0. Границы задачи — читать до начала

1. **Экранов ровно семь.** Пустой список (изменение существующего), строка в Настройках → Хранилище (изменение существующего), Шаг 1, шторка «Как выгрузить», Шаг 2, Шаг 3 (три состояния одного окна: ход / отчёт / список пропущенного). Ничего восьмого не добавлять.
2. **Выбора источника нет.** Ни экрана, ни списка, ни радиокнопок, ни логотипов Obsidian / Bear / Notion / Evernote. Определение — по содержимому (§3).
3. **Раздела «Импорт» в навигации нет.** Только две точки входа из §1.
4. **Цвета брать из токенов `zapiski.css`** (`--accent`, `--surface`, `--line`, `--text-secondary`, …). Hex-значения в макетах хода 6 — палитра макета, не продукта; копировать их в код запрещено.
5. **Тексты — дословно из этого документа.** Строки, которой здесь нет, на экране быть не должно. Никаких восклицательных знаков, слов «ошибка», «сбой», «внимание». Обращение — «вы».
6. **Ничего не выдумывать при неоднозначности** — оставить TODO в коде и спросить.

## 1. Точки входа — ровно две

### 1.1. Пустой список заметок (`#6a`)
К существующему пустому состоянию добавляется **одна текстовая ссылка под основной кнопкой**:

- Заголовок: `Здесь пока тихо` (существует)
- Подпись: `Первая заметка займёт секунду` (существует)
- Кнопка: `Новая заметка` (существует, primary, не менять)
- **Новое:** ссылка `Перенести из другого приложения` — цвет `--accent-text`, размер 14px, `margin-top: 16px` от кнопки, выравнивание по центру, высота тапа ≥44px.

Кнопки-иконки, второй primary, картинки-иллюстрации — запрещены.

## 2. Мастер — три шага, одно окно

Веб/десктоп: модальное окно **560px**, `border-radius: var(--r-panel)`, `box-shadow: var(--shadow-pop)`, скрим `var(--scrim)`, паддинг 28–30px / 32px.
Телефон: **та же логика** в bottom sheet, радиус `20px 20px 0 0`, `box-shadow: var(--shadow-sheet)`, паддинг 24px, кнопки высотой 52px во всю ширину (`#6h`).

Счётчик шага — в правом верхнем углу, моно, 11px, `--text-tertiary`: `1 / 3`, `2 / 3`, `3 / 3`. **Моно — только счётчик, пути файлов и числа. Больше нигде.**

### Шаг 1 (`#6c`, телефон — `#6h`)

- Заголовок: `Перенести заметки`
- Подзаголовок: `Отдайте папку или архив — разберёмся сами.`
- Зона: пунктир `1.5px dashed var(--line)`, радиус 18px, фон `var(--bg)`, паддинг 34px 20px, по центру: иконка загрузки 30px `--accent`, текст `Перетащите сюда папку или архив`, кнопка-secondary `Выбрать на компьютере`.
- Телефон: без пунктирной зоны — две кнопки: primary `Выбрать папку`, secondary `Выбрать архив` (системный picker / SAF).
- Ряд чипов, префикс `Узнаём сами:` затем чипы `Obsidian` `Bear` `Notion` `Evernote` `любые .md` — фон `var(--surface-sunken)`, радиус `--r-full`, 13px. **Чипы не кликабельны.** Это обещание, не фильтр.
- Разделитель, затем ссылка `Как выгрузить заметки из старого приложения` (открывает §2.4) и справа `Отмена`.

### Шаг 2 (`#6e` — Obsidian, `#6f` — Notion)

Заголовок = **утверждение о том, что нашли**, одна из строк:

- `Это хранилище Obsidian`
- `Это заметки Bear`
- `Это экспорт Notion`
- `Это архив Evernote`
- `Это папка с markdown` — фолбэк, когда источник не опознан
- `Не удалось прочитать это` — если внутри нет ни одного поддерживаемого файла; единственное действие `Выбрать другую папку`

Подзаголовок: `Папка ` / `Архив ` + имя моно + ` · ` + размер.

Три плитки-счётчика (`var(--bg)`, `1px var(--line)`, `--r-md`, число 22px/700 `tabular-nums`, подпись 12.5px):

| Источник | Плитки |
| --- | --- |
| Obsidian / Bear / .md | `заметок` · `вложений` · `папок` |
| Notion | `страниц` · `вложений` · `баз данных` |
| Evernote | `заметок` · `вложений` · `блокнотов` |

Строка «Положить в»: иконка папки, надпись 12px `Положить в`, значение 14.5px = имя целевой папки + ` · со структурой папок` (Notion: `со структурой страниц`), справа ссылка `Изменить`. **Имя целевой папки по умолчанию = имя источника** (`Obsidian`, `Bear`, `Notion`, `Evernote`, `Импорт` для неопознанного).

Затем **три строки гарантий** (галочка `--success` / инфо `--text-tertiary`, 13.5px):

1. `Вложения и ссылки [[wiki]] перенесём рабочими` — для Obsidian; для остальных: `Вложения и ссылки перенесём рабочими`
2. `Frontmatter останется в файлах, теги подхватим` — Obsidian; Bear: `Теги #работа/клиенты станут вложенными тегами`; Notion/Evernote: `Заголовки, списки и таблицы станут markdown`
3. `Существующие заметки не тронем: при совпадении имён добавим суффикс` — **во всех случаях, обязательна**

**Блок «Что станет проще, чем было»** — показывать только когда есть потери. Фон `--warning-soft`, рамка `#EADFC7`/`color-mix(--warning 30%)`, радиус `--r-md`. Заголовок `Что станет проще, чем было`, ниже 1–3 строки, генерируемые по факту сканирования:

- `N баз данных станут таблицами markdown. Фильтры и виды не переносятся.`
- `Вложенные страницы станут папками с заметкой-обложкой.`
- `N файлов — .csv и встроенные виджеты — приложим к заметке как есть.`
- Evernote: `Сложная вёрстка таблиц станет markdown-таблицей.`, `N рукописных вложений приложим картинками.`

**Правило: о потерях сообщаем до запуска, а не в отчёте.** Показывать этот блок после старта запрещено.

Низ: primary `Перенести 1 240 заметок` (число из скана, `tabular-nums`; Notion — `Перенести 640 страниц`), рядом текстовая `Назад`.

### Шаг 3 — три состояния одного окна (`#6g`)

**Ход.** Заголовок `Переносим`. Подпись `812 из 1 240 · осталось около минуты` (`tabular-nums`; при неизвестном времени — только счётчик). Полоса 6px, радиус `--r-full`, фон `--surface-sunken`, заливка `--accent`. Ниже — текущий путь, моно 11.5px, `--text-tertiary`, обрезка с середины. Действия: secondary `Свернуть`, текстовая `Остановить`.
**Перенос не блокирует приложение.** «Свернуть» → строка в списке заметок (`#6i`): `Переносим · 812 из 1 240`, ссылка `Подробно`, полоса 4px. Прогресс переживает свёртывание, но не перезапуск приложения (при перезапуске — незавершённый импорт откатывается молча, уже перенесённые заметки остаются).
«Остановить» → подтверждение: `Остановить перенос? Уже перенесённые заметки останутся.` / `Остановить` · `Продолжить`.

**Отчёт.** Кружок-галочка 34px `--success-soft`/`--success`. Заголовок `Перенесли 1 237 заметок`. Подпись при пропусках: `3 файла пропустили — их не удалось прочитать. Они остались у вас на диске.` Без пропусков — подписи нет.
Сводка (`--bg`, `--r-md`), три строки «label — число, tabular-nums»: `Вложений перенесено`, `Ссылок переписано`, `Имён с суффиксом`. Строку с нулём не показывать.
Действия: primary `Открыть папку «Obsidian»` (имя целевой папки), рядом ссылка `Что пропустили` — только если пропуски есть.

**Список пропущенного.** Заголовок `Что пропустили`, крестик. Список: путь моно 12.5px + причина 12.5px `--text-secondary`, разделители `--line-soft`. Причины — из фиксированного набора:

| Причина | Текст |
| --- | --- |
| Не читается | `Файл повреждён — не читается` |
| Формат не поддержан | `Формат Obsidian Canvas не поддерживается` (подставить имя формата) |
| Слишком большой | `Больше 200 МБ — оставили на диске` |
| Нет доступа | `Нет доступа к файлу` |

Внизу: `Список можно скопировать: пути ведут к вашим исходным файлам, ничего не удалено.` и secondary `Скопировать список`. Копируется plain text: путь + tab + причина.

### 2.4. Шторка «Как выгрузить» (`#6d`)

Правая панель **440px** (телефон — bottom sheet на всю высоту). Заголовок `Как выгрузить заметки`, крестик. Сегмент-контрол 4 позиции: `Obsidian` `Bear` `Notion` `Evernote` — существующий компонент `SegmentedControl`, без вертикальных табов.

Тело — **статичный текст, вшитый в сборку**. Ни fetch, ни markdown-рендера, ни скриншотов, ни ссылок на сайты источников. Формат на каждый источник: 3 нумерованных шага (кружок 22px `--accent-soft`, цифра `--accent-text`), затем блок-примечание (`--bg`, `--r-md`), затем одна строка-приписка `--text-tertiary`.

**Obsidian**
1. `Ничего выгружать не нужно: хранилище Obsidian — это обычная папка с файлами .md.`
2. `Найдите её на диске — путь виден в Obsidian: «Настройки» → «О программе» → «Открыть папку хранилища».`
3. `Укажите эту папку в окне переноса.`
Примечание: `Папку .obsidian с настройками и плагинами не переносим — темы и плагины ЗАПИСКАМ не нужны.`
Приписка: `Заметки останутся у вас и в Obsidian — мы копируем, а не переносим.`

**Bear**
1. `В Bear на Mac: «Файл» → «Экспортировать заметки».`
2. `Формат — Markdown. Включите «Экспортировать вложения».`
3. `Сохраните папку и перетащите её в окно переноса.`
Примечание: `Теги вида #работа/клиенты станут вложенными тегами ЗАПИСОК как есть. Сноски и подсветка сохранятся.`
Приписка: `Экспорт в .bearnote тоже подойдёт — прочитаем его.`

**Notion**
1. `В Notion: «…» у названия рабочего пространства → «Settings» → «Export all workspace content».`
2. `Формат — Markdown & CSV, «Include subpages» включить.`
3. `Придёт письмо со ссылкой на .zip — укажите этот архив в окне переноса.`
Примечание: `Базы данных станут таблицами markdown. Виды, фильтры и формулы не переносятся — их видно на шаге 2 до запуска.`
Приписка: `Распаковывать архив не нужно.`

**Evernote**
1. `В Evernote выделите блокнот → правая кнопка → «Экспортировать заметки».`
2. `Формат — .enex, «Включить вложения».`
3. `Укажите файл .enex в окне переноса. Файлов может быть несколько — можно указать все сразу.`
Примечание: `Сложная вёрстка таблиц станет markdown-таблицей. Рукописные заметки приложим картинками.`
Приписка: `Веб-клипы сохранятся текстом со ссылкой на источник.`

Низ шторки: primary `Вернуться к переносу`.

## 3. Определение источника — порядок проверок

Первое совпадение выигрывает:

1. Внутри есть каталог `.obsidian/` → **Obsidian**
2. Есть `.enex`-файлы (или указан сам `.enex`) → **Evernote**
3. Есть `.textbundle` / `.bearnote` → **Bear**
4. ≥30% имён `.md`/`.html` заканчиваются на ` <32-символьный hex>` или содержат папку с таким хвостом → **Notion**
5. Есть хоть один `.md` → **папка с markdown**
6. Иначе → `Не удалось прочитать это`

Определение — **только по структуре и именам, без сети и без телеметрии.**

## 4. Правила переноса

1. **Импорт никогда не перезаписывает существующие заметки.** Коллизия имени → суффикс ` 2`, ` 3`, …
2. Вложения кладутся **рядом с заметкой**, относительные пути в тексте переписываются на новые. Битая ссылка на вложение — не причина пропускать заметку.
3. `[[wiki-ссылки]]` сохраняются как есть; при переименовании из-за коллизии ссылки на переименованный файл обновляются, счётчик попадает в отчёт (`Ссылок переписано`).
4. Frontmatter не трогаем. Теги из frontmatter и из текста подхватываем в индекс.
5. Исходные файлы пользователя **не удаляются и не изменяются никогда**. Импорт — копирование.
6. Лимит одного вложения — 200 МБ; сверх — пропуск с причиной, заметка переносится без него.
7. Прерывание/сбой на файле = пропуск + строка в отчёте, конвейер продолжается. Целиком импорт не падает.
8. Ход импорта не пишется в облако и не покидает устройство.

## 5. Тосты и ошибки — брать только отсюда

| Ситуация | Текст |
| --- | --- |
| Импорт завершён (свёрнутый) | `Перенесли 1 237 заметок · Открыть` |
| Импорт частично не удался | `Импортировано N · Пропущено M — показать` |
| Нет доступа к папке | `Папка недоступна. Возможно, её переместили — укажите новое расположение` |

| Нет места на диске | `На устройстве закончилось место. Перенесено N заметок — освободите место и продолжите` |
| Импорт остановлен | `Перенос остановлен · Перенесено N` |

## 6. Запрещено

- Экран или список выбора источника; логотипы и иконки чужих продуктов.
- Отдельный раздел «Импорт» в настройках или в меню.
- Модальность на время переноса (блокирующий спиннер во весь экран).
- Проценты вместо «812 из 1 240».
- Скриншоты, видео, анимированные иллюстрации в инструкциях.
- Сообщение о потерях **после** запуска переноса.
- Сетевые запросы, аналитика и телеметрия в любом месте флоу импорта.
- Hex-цвета и магические отступы в коде вместо токенов `zapiski.css`.
- Слова «ошибка», «сбой», «внимание», восклицательные знаки, «ты».
