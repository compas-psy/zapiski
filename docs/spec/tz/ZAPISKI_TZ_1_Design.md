# ТЗ для Claude Design — ЗАПИСКИ

**Версия 2.0 · финальная.** Это не бриф с нуля: базовая дизайн-система уже сделана (файл «Дизайн-система с темами», ходы 1–4). Документ фиксирует принятое, задаёт правки и перечисляет недостающее.

## 1. Что принято и не пересматривается

| Параметр | Значение |
| --- | --- |
| Имя в интерфейсе | **ЗАПИСКИ** (издатель СИМПАС — только в сторе, счетах, юр. текстах) |
| Базовая тема | **«Бумага»**, светлая |
| Акцент по умолчанию | **«Гранат»** — во всех темах, во всех поверхностях, включая иконку |
| Тёмные темы | «Графит» (обычная) и «Чернила» (OLED) |
| Шрифты | Golos Text (UI + заметки), Source Serif 4 («бумажный» режим), JetBrains Mono (код, даты, raw) |
| Голос | **Убрать из v1.** Микрофон из тулбара редактора удалить, экраны 3a–3e перевести в отдельный файл «P1 · Голос» |

### Правки к готовым макетам (сделать до передачи в код)

1. **Убрать все упоминания КОМПАС и Окоём.** «Облако КОМПАС» → **«Облако Записок»**. Домен в браузерном хроме `zapiski.cmpas.ru` → плейсхолдер `zapiski.pro` (финальный домен уточняется).
2. **Убрать чип «КОМПАС.Дневник → карточка клиента»** из заметки (экран 1r). Связь между продуктами односторонняя и живёт в приложении практики, не здесь.
3. **Заменить весь демо-контент на неклинический.** Сейчас в макетах: «Конспект супервизии — случай М.», гипотеза о клиентке, прямая цитата клиентки. Убрать полностью — из списка, поиска, витрины, голосовых экранов. Замена той же тональности и плотности: конспект книги, заметки с вебинара, дневник («моё нетерпение — не помощь» — эталон, там нет клиента), чек-лист переезда кабинета, идеи для канала, планы месяца.
4. **Микрофон из тулбара редактора убрать**, освободившееся место отдать «…» (ещё).
5. **Копирайт шифрования:** «Заметка зашифрована на этом устройстве» → **«Заметка зашифрована. Ключ только у вас»** (зашифрованный файл синхронизируется тоже — формулировка должна быть точной).
6. **Сократить акцентные пресеты с 6 до 3** к запуску: Гранат (базовый), Черника, Грифель. Остальные — после релиза. 3 темы × 6 акцентов = 18 комбинаций, которые пришлось бы регрессить на каждом релизе.
7. **Иконка:** знак-дерево на гранатовом фоне. Новый знак не рисуем. Отдать в трёх форматах: Android adaptive (foreground/background раздельно), Windows `.ico` 16–256, favicon/PWA 192/512.

## 2. Токены (сверить с источником — значения сняты с макета)

```
Тема «Бумага» (светлая, базовая)
  фон        #FBFAF7      поверхность #F3F1EA
  текст      #38342E      вторичный   #726C60
  линия      #EAE6DB

Тема «Графит» (тёмная, тёплый графит — не чёрный)
  фон        #232128      поверхность #2C2A28
  текст      #E9E5DC      вторичный   #98948A
  линия      #393630

Тема «Чернила» (OLED, истинный чёрный)
  фон        #000008      поверхность #151412
  текст      #E9E5DC      вторичный   #8F887D
  линия      #26231E

Акцент      Гранат (терракотовый) — hex взять из источника дизайн-системы
Форма       радиусы 10 / 12 / 14 · линии 1px вместо теней · elevation только модалки · иконки stroke 1.75
Motion      200–300 мс · ease-out · без пульсаций и бейджей · хэптика на чекбоксах и завершениях
            reduce-motion → всё статично
Типографика Заголовок 26/700 · Подзаголовок 19/600 · Текст 16/1.65 · Вторичный 13 · подписи 11 caps
Плотности   обычная 16/1.65 · бумажная Source Serif 17/1.7 · компактная 14.5/1.5
```

**Обязательная проверка контраста:** Гранат на «Бумаге» и на «Чернилах» — 4.5:1 для текста и 3:1 для интерактивных границ. Если базовый гранат не проходит на светлом фоне, вводится отдельный токен `accent-text` (затемнённый) при сохранении базового для заливок.

**Формат сдачи токенов:** `tokens.json` (W3C Design Tokens) — единственный артефакт, по которому код получает цвета, типографику, радиусы и motion. Хардкод цветов в макетах и коде запрещён.

### 3.2. Недостающее — сделать (приоритет сверху вниз)

**И1. Импорт — 4 экрана. Наивысший приоритет: это первый экран целевого пользователя.**
- И1.1 Выбор источника: Obsidian (папка) · Bear (`.bear2bk`) · Notion (zip) · Evernote (`.enex`) · просто папка с `.md`. Каждая карточка — с одной строкой «что перенесётся».
- И1.2 Превью до импорта: «Нашли 1 240 заметок, 380 вложений, 96 тегов, 12 папок. Перенесём как есть». Выбор папки назначения.
- И1.3 Процесс: прогресс, отменяемо, работает в фоне.
- И1.4 Итог с честным отчётом: что перенеслось, что не смогли и почему (список, экспортируемый в файл). Кнопка «Открыть первую заметку».

**И2. Изображения и вложения — 5 состояний.** Это наш козырь против главной боли Obsidian, он должен быть виден:
вставка из камеры / из галереи / из буфера · загрузка (плейсхолдер с прогрессом) · нормальный вид инлайн · **«файл не найден»** — спокойное состояние с путём и кнопкой «найти» · просмотр во весь экран с зумом и шарингом.

**И3. Планшет Android, брейкпоинты 600 / 900 / 1200.** Две панели (список + редактор), три панели на 1200, поведение при повороте, разделитель с перетаскиванием.

**И4. Аккаунт и подписка:** экран аккаунта · управление подпиской · **состояние «подписка истекла»** (заметки доступны, облако отключено — самый важный экран честности) · восстановление покупок.

**И5. Экспорт:** выбор формата (md / PDF / HTML / DOCX), одна заметка / выбранные / всё, превью PDF.

**И6. Настройки целиком:** внешний вид · редактор · синхронизация · безопасность · экспорт и импорт · о приложении (с указанием издателя СИМПАС и лицензий).

**И7. Ошибки синка:** нет сети · неверные учётные данные WebDAV · закончилось место · сервер отвечает ошибкой. Тон: спокойный, всегда с «что сделать».

**И8. Первый запуск на втором устройстве:** подключение к тому же хранилищу, первичная загрузка, «догоняем — писать уже можно».

## 4. Матрица состояний

Для каждого экрана из §3 обязательны: обычное · пустое · загрузка (скелетоны, не спиннеры) · оффлайн · ошибка · заперто шифрованием (где применимо) · длинный контент (заметка 5 000 слов, 300 заметок в папке, тег с 30 символами).

## 5. Доступность

WCAG 2.1 AA. Контраст 4.5:1 для текста и 3:1 для границ во **всех трёх темах** с гранатовым акцентом. Touch-targets ≥44dp. Полная навигация с клавиатуры на десктопе, TalkBack/Narrator на всех экранах. Масштаб шрифта ОС до 200% без поломки layout — проверить на списке заметок, редакторе и онбординге. Режим сниженной анимации.

## 6. Deliverables

1. `tokens.json` — W3C Design Tokens, 3 темы × 3 акцента, типографика, spacing, радиусы, motion.
2. Библиотека компонентов в светлой и тёмной темах, все состояния (готово — обновить под 3 акцента).
3. Все экраны §3.1 с внесёнными правками + все экраны §3.2.
4. Три форм-фактора: phone 390×844 · tablet 900 · desktop/web 1440.
5. Витринная заметка со всеми markdown-элементами — эталон рендеринга, в 3 темах × 3 плотностях × serif/sans. Это приёмочный артефакт для кода.
6. Прототипы двух флоу: «импорт из Obsidian → первая заметка» и «первая заметка за 60 секунд».
7. Иконка в трёх форматах + скриншоты для сторов (6 штук, неклинический контент).
8. Отдельный файл «P1 · Голос» — всё, что перенесено из ходов 3 и 4c–4d.

## 7. Приёмка дизайна

- Ни на одном экране, скриншоте и в прототипе нет клинического контента, имён клиентов и их цитат.
- Ни на одном экране нет слов «КОМПАС», «Окоём», домена cmpas.ru.
- Гранат проходит контраст во всех трёх темах (проверено инструментом, не на глаз).
- В режиме чтения/письма текст заметки занимает ≥80% площади экрана.
- Тёмные темы проверены на OLED-устройстве, без «грязных» серых заливок.
- Слепое сравнение витринной заметки с Bear на 5–8 людях: не хуже по субъективной оценке.
- `tokens.json` открывается и валидируется; в макетах нет цветов вне токенов.
