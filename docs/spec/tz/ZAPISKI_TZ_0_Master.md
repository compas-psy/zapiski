## 1. Продукт

**Одна фраза:** тихая комната для мыслей — быстрый красивый Markdown-заметочник, где файлы принадлежат вам.

Локальные `.md`-файлы, опциональное шифрование, синхронизация, которая просто работает: бесплатно — через своё хранилище (WebDAV, Яндекс.Диск, локальная папка), по подписке — через Облако Записок. Ориентиры по духу: Bear (лаконичность, отсутствие трения) и Obsidian (владение данными). **Не Notion**: никаких баз данных.

### Пустота на рынке (по результатам исследования)

| Продукт | Чего нет — и это наш вход |
| --- | --- |
| **Bear** | Нет Windows, Android, Linux. Синхронизация только по подписке. Нет голоса. В вебе нет шифрования и экспорта |
| **Obsidian** | Android-версия годами глючит (символы-призраки, клавиатура, скролл). Конфликты синка. Плагины ломаются при обновлениях. Порог входа |
| **Notion** | Тяжёлый, медленный, данные не ваши |
| **Simplenote** | Бесплатный и везде, но без медиа и без полировки |

**Формула позиционирования:** красота Bear + открытость Obsidian + честный бесплатный синк + все платформы.

## 2. Продуктовые принципы (немодифицируемые)

1. **File over app.** Заметка — это `.md`-файл. Приложение умрёт — заметки останутся.
2. **Заметки, а не база данных.** Красная линия навсегда.
3. **Ноль трения.** От иконки до курсора в новой заметке — меньше 2 секунд.
4. **Приватность по умолчанию.** Шифрование бесплатно. Мы технически не можем прочитать зашифрованное.
5. **Никаких плагинов.** Урок Obsidian: экосистема плагинов = поломки при каждом обновлении.
6. **Бесплатное — честно бесплатное.** Платим за удобство (облако), не за снятие искусственных ограничений.

## 3. Аудитория

**Первичная — «беженцы».** Пользователь Android/Windows, который хочет Bear, но не может; пользователь Obsidian, уставший от мобильного клиента и платного синка; пользователь Notion, уставший от тяжести. 25–45, пишет ежедневно.

**Вторичная — помогающие специалисты.** Личные профессиональные заметки: конспекты обучения, книг, вебинаров, рефлексия. **Не заметки о клиентах** — они живут в приложении практики (см. §7).

## 4. Скоуп

### P0 — первый релиз

**Редактор:** гибридный live-preview Markdown (синтаксис проявляется у курсора) + raw-режим. H1–H6, bold/italic/strike/`==highlight==`, списки, чекбоксы, цитаты, код с подсветкой, таблицы GFM, изображения, ссылки, `[[wiki-ссылки]]`, сноски, разделители.
**Организация:** папки + вложенные теги `#практика/супервизия`, закрепление, архив, корзина (30 дней).
**Поиск:** мгновенный FTS с чипами-фильтрами (`tag:`, `folder:`, даты, `has:вложение`), поиск внутри заметки.
**Связи:** backlinks-панель. Графа нет.
**Вложения:** изображения и файлы, единая конвенция относительных путей на всех платформах.
**Шифрование:** заметка/папка → AES-256-GCM, пароль + биометрия. Работает везде, включая веб.
**Синхронизация:** локально · WebDAV · Яндекс.Диск (нативно) · Облако Записок (подписка).
**Импорт:** Obsidian-vault, Bear, Notion, Evernote. **Экспорт:** md, PDF, HTML, DOCX — бесплатно.
**Платформы:** Android phone, Android tablet, Windows, Web (PWA).

### P1 — 3–9 месяцев

Голос → Markdown (GigaAM + Qwen, обработка на устройстве или в облаке) · шаблоны заметок · виджеты и share-target (если не успели в P0) · веб-клиппер · публикация заметки по ссылке · история версий с визуальным diff · iOS / iPadOS / macOS.

### P2 — второй год

Совместное редактирование отдельных заметок · рукописный ввод на планшетах · семантический поиск · сопряжение с домашним ПК для голоса · Linux.

### Никогда

Базы данных и формулы · канбан · календарь-планировщик · таск-менеджер с напоминаниями · сторонние плагины · геймификация · лента.

## 6. Метрики

- **NSM:** недель, в которых пользователь писал ≥3 дня.
- Активация: 2-я заметка в первые 24 часа · настроенный синк за 7 дней · успешный импорт (для «беженцев»).
- Retention W4 / M3 · конверсия free→paid · доля сессий с конфликтом синка (цель <0.5%) · crash-free >99.8%.

## 7. Приватность, 152-ФЗ и правило клинического контента

**Правило продукта, обязательное для дизайна, кода и маркетинга:**

1. ЗАПИСКИ — общегражданский продукт. Мы **нигде** не предлагаем, не показываем и не подразумеваем хранение в нём данных клиентов помогающих специалистов.
2. Демо-контент, скриншоты сторов, маркетинг: конспекты книг и вебинаров, дневник, списки, рабочие планы, рефлексия о себе. **Запрещено:** имена/инициалы клиентов, цитаты клиентов, диагнозы, формулировки «случай N», «конспект супервизии по клиенту».
3. Заметки о клиентах живут в приложении практики, где шифрование и серверы в РФ обязательны архитектурно.
4. Deep-link между продуктами — **однонаправленный**: из практики можно открыть Записки; заметка в Записках не ссылается на карточку клиента.
5. Если движок Записок встроен в приложение практики — он работает в **режиме host-policy** (см. `2_Engineering.md`, §9): принудительное шифрование, запрет внешних бэкендов синка, запрет публикации.
6. Аналитика: opt-in, только продуктовые события, **никогда** содержимое заметок, заголовки или имена файлов.

## 8. Риски

| Риск | Вероятность | Влияние | Митигация |
| --- | --- | --- | --- |
| Качество мобильного ввода (то, на чём горит Obsidian) | Высокая | Критическое | Спайк №1 до старта; выделенный QA-агент; матрица клавиатур как gate релиза |

| «Ещё один заметочник», не пробиваемся | Средняя | Высокое | Позиционирование от чужой боли, бесплатный честный тариф, импорт в один клик |
| Слабая охрана знака «Записки» | Высокая | Среднее | Комбинированный знак, подача до публичного анонса |
| Фонетика СИМПАС ↔ КОМПАС | Низкая | Среднее | Проверка поверенным до регистрации юрлица |
| Задержка iOS отсекает часть «беженцев» из Bear | Высокая | Среднее | Веб-версия как временный вход для Apple; iOS в P1 первым пунктом |
