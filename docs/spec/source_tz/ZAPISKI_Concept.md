# КОМПАС.ЗАПИСКИ — Концепция продукта

*Заметочное приложение семейства КОМПАС. Рабочее название — «ЗАПИСКИ» (альтернативы: МЫСЛИ, СТРОКИ, ПОЛЯ).*

Версия 1.0 · Август 2026 · Конфиденциально

---

## 1. Суть продукта в одном абзаце

**ЗАПИСКИ** — спокойное, красивое, быстрое приложение для заметок в формате Markdown. Локальные `.md`-файлы, опциональное шифрование, синхронизация «которая просто работает»: бесплатно — через своё хранилище (WebDAV, Яндекс.Диск, локально), по подписке — через облако КОМПАС. Ориентиры по духу — Bear (лаконичность, отсутствие трения) и Obsidian (владение данными, открытый формат). **Не** Notion: никаких баз данных, таблиц-как-БД, канбанов. Только заметки, сделанные идеально.

## 2. Почему сейчас и почему мы

### 2.1. Пустая ниша (по итогам исследования)

| Продукт | Сила | Провал (жалобы пользователей) |
| --- | --- | --- |
| **Bear** | Лучший UX/дизайн в классе, markdown без трения | Только Apple. Нет Windows/Android. Синк только платный. Нет голосовых заметок. В вебе нет шифрования и экспорта |
| **Obsidian** | Открытые .md, владение данными, мощь | Android-версия годами глючит (клавиатура, символы, скролл). Конфликты синка. Синк платный. Хаос плагинов, ломающихся при обновлениях. Порог входа |
| **Notion** | Всё-в-одном | Медленный, перегруженный, данные не твои, оффлайн слабый |
| **Simplenote** | Бесплатный, везде | Только текст, нет медиа, нет полировки |

**Вывод:** в мире нет продукта «красота Bear + открытость Obsidian + кроссплатформенность + честный бесплатный синк». В России — тем более (уход западных сервисов, потребность в локальном хранении, 152-ФЗ).

### 2.2. Синергия с семейством КОМПАС

- Общий дизайн-язык «спокойной рабочей среды» — бренд уже спроектирован.
- Готовая GTM-машина: те же профессиональные Telegram-сообщества, амбассадоры, вебинары.
- Помогающие специалисты — идеальный beachhead для заметочника: пишут много, ценят приватность, уже доверяют бренду. Но продукт — **general-purpose**, аудитория шире (студенты, писатели, разработчики, все, кто ушёл из Notion/Evernote).
- Мост в экосистему: заметку можно (опционально) привязать к карточке клиента в КОМПАС.Дневнике — deep link, не слияние продуктов.

## 3. Продуктовые принципы (немодифицируемые)

1. **File over app.** Каждая заметка — это `.md`-файл на диске пользователя. Приложение умрёт — заметки останутся.
2. **Заметки, а не база данных.** Мы сознательно НЕ делаем: реляционные таблицы, формулы, канбаны, календари-планировщики, задачники с напоминаниями. Красная линия навсегда.
3. **Ноль трения.** От иконки до курсора в новой заметке — меньше 2 секунд. Всегда.
4. **Приватность по умолчанию.** Шифрование доступно бесплатно. Мы технически не можем читать зашифрованные заметки пользователя.
5. **Никаких плагинов.** Урок Obsidian: экосистема плагинов = хаос и поломки. Вместо этого — тщательно отобранный встроенный функционал, который работает всегда.
6. **Бесплатное — честно бесплатное.** Весь функционал доступен бесплатно, включая синк через своё хранилище. Платим за удобство (облако КОМПАС), не за снятие искусственных ограничений.

## 4. Аудитория

### 4.1. Первичная: «беженцы» из Bear/Obsidian/Notion

Пользователь Android и/или Windows, который хочет Bear, но не может; либо пользователь Obsidian, уставший от глючного мобильного клиента и платного синка; либо пользователь Notion, уставший от тяжести. 25–45 лет, пишет ежедневно: дневник, рабочие заметки, конспекты, черновики.

### 4.2. Вторичная: помогающие специалисты (Марина)

Личные профессиональные заметки, не привязанные к клиентам: конспекты супервизий, обучения, статей, рефлексия. Мост к КОМПАС.Дневнику.

## 5. Функциональный скоуп

### 5.1. Ядро (MVP, P0)

- **Редактор:** гибридный Markdown (стилизация на лету, как Bear/Obsidian Live Preview; переключение в raw-режим). Заголовки, списки, чекбоксы, таблицы (простые, markdown), код с подсветкой, цитаты, изображения, ссылки, wiki-ссылки `[[заметка]]`, выделение ==текста==, сноски.
- **Организация:** папки + вложенные теги `#работа/клиенты` (и то и другое — урок Bear: только-теги путают людей). Закреплённые заметки. Архив. Корзина с восстановлением.
- **Поиск:** мгновенный полнотекстовый, с операторами (тег, папка, дата, `has:image`), поиск внутри заметки.
- **Связи:** backlinks-панель («что ссылается на эту заметку»). Без графа на старте — граф Obsidian красив, но им не пользуются.
- **Вложения:** изображения (с корректными относительными путями — главная боль Obsidian!), файлы. Хранятся рядом с .md в папке `attachments/`.
- **Шифрование:** заметка или папка → AES-256-GCM, пароль/биометрия. Зашифрованный файл остаётся валидным файлом на диске (`.md.enc`). Работает на всех платформах, включая веб (в отличие от Bear).
- **Экспорт:** md, PDF, HTML, DOCX — бесплатно (боль Bear: экспорт за paywall).
- **Тёмная/светлая тема,** типографика класса Bear.

### 5.2. Синхронизация (ключевой дифференциатор)

| Режим | Тариф | Как работает |
| --- | --- | --- |
| Локально | Бесплатно | Папка на устройстве, полный оффлайн |
| Своё хранилище | Бесплатно | WebDAV (любой), Яндекс.Диск (нативная интеграция), любая папка, синхронизируемая сторонним клиентом |
| Облако КОМПАС | Подписка | E2E-шифрование, версионирование 30–365 дней, мгновенный синк, веб-доступ, шаринг |

**Гибридное хранение:** заметки могут жить локально И в облаке одновременно; при конфликте главной считается облачная версия, локальная сохраняется как версия в истории. Разрешение конфликтов — автоматическое на уровне блоков (CRDT/three-way merge), не «выбери файл» — прямой ответ на главную жалобу Obsidian-пользователей.

### 5.3. P1 (3–9 месяцев после запуска)

- Голосовые заметки с транскрибацией (боль Bear; синергия с AI-помощником КОМПАС).
- Шаблоны заметок (в т.ч. профессиональные наборы: конспект супервизии, дневник, daily note).
- Быстрый ввод: виджет Android, глобальный хоткей Windows, share-target из любого приложения.
- Веб-клиппер (браузерное расширение → чистый markdown).
- Публикация заметки по ссылке (read-only, красивая страница).
- История версий заметки (визуальный diff).

### 5.4. P2 (второй год)

- Совместное редактирование выбранных заметок (не «командный workspace» — только шаринг конкретной заметки).
- Рукописный ввод / скетчи на планшетах.
- AI-слой: семантический поиск, «суммаризируй заметку», связанные заметки. Строго опционально и отключаемо.

### 5.5. Анти-скоуп (никогда)

Базы данных и формулы · канбан-доски · встроенный календарь-планировщик · таск-менеджер с напоминаниями · сторонние плагины · геймификация · лента/соцсеть.

## 6. Платформы

| Платформа | Приоритет | Роль |
| --- | --- | --- |
| Android (mobile) | **P0** | Главная точка захвата мысли. Редактор должен быть безупречен — это то, что Obsidian провалил |
| Windows (desktop) | **P0** | Основное место длинного письма |
| Web (PWA) | **P0** | Доступ отовсюду + бесплатная точка входа без установки |
| Android (tablet) | P0.5 | Адаптивный layout из mobile-кодовой базы, двухпанельный режим |
| iOS / iPadOS | P1 | 6–9 мес после запуска |
| macOS | P1 | Вместе с iOS |
| Linux | P2 | Дёшево из Windows-сборки, лояльная аудитория |

## 8. GTM (кратко)

1. **Волна 1 — своя аудитория:** пользователи КОМПАС.Дневника и МОМЕНТОВ, Telegram-канал, амбассадоры. Бесплатный тариф = нулевой барьер.
2. **Волна 2 — «беженцы»:** контент «Bear для Android наконец существует», «Obsidian без боли», посевы в r/PKM-подобных русскоязычных сообществах, Telegram-каналы о продуктивности, обзорщики приложений.
3. **Волна 3 — вирусность продукта:** публикация заметок по ссылке (красивая страница с ненавязчивым «Создано в ЗАПИСКАХ»), шаринг зашифрованных заметок.

## 9. Метрики

- **NSM:** недель с ≥3 днями создания/редактирования заметок (habit-метрика).
- Активация: 2-я заметка в первые 24 часа; настроенный синк в первые 7 дней.
- Retention W4 / M3; конверсия free→paid; NPS редактора.

## 10. Риски

| Риск | Mitigation |
| --- | --- |
| «Ещё один заметочник» — рынок переполнен | Позиционирование от боли (Android/Windows-пустота Bear, глючность Obsidian), бесплатный честный тариф, бренд КОМПАС |
| Качество мобильного редактора (то, на чём горят все) | Редактор — единая кодовая база на всех платформах; 40% времени QA — именно мобильный ввод, клавиатуры, IME, кириллица |
| Конфликты синка портят доверие | CRDT-архитектура с первого дня; версионирование как страховка; конфликт никогда не теряет данные |
| Каннибализация фокуса команды с Дневника | Отдельный небольшой поток (1–2 разработчика + Claude Code), общий дизайн-язык снижает стоимость |
