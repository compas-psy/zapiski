# ТЗ для Claude Design — КОМПАС.ЗАПИСКИ

*Дизайн-бриф. Продукт: заметочное приложение семейства КОМПАС (Android mobile/tablet, Windows, Web; iOS/macOS — later).*

---

## 1. Контекст и настроение

**Одна фраза:** тихая комната для мыслей.

ЗАПИСКИ — часть семейства КОМПАС («спокойная рабочая среда для помогающих практик»). Дизайн-ДНК семейства: спокойная палитра, минимальный интерфейс, отсутствие «админки», бережный тон. ЗАПИСКИ — самый интимный продукт семейства: сюда пишут дневники, черновики, мысли. Интерфейс должен исчезать.

**Эталоны:** Bear (типографика, лёгкость, тёплый минимализм), iA Writer (фокус, отсутствие хрома), Things 3 (детализация анимаций, «дороговизна» простоты), iOS HIG как общая логика лаконичности — при этом на Android соблюдаем платформенные жесты и паттерны (не делать «iOS-скин на Android», а перенести дух: воздух, сдержанность, глубина через типографику, а не через декор).

**Анти-эталоны:** Notion (перегруз, серость), Evernote (хром, тулбары), стандартные Material-виджеты «из коробки» без характера.

## 2. Принципы

1. **Текст — главный герой.** 90% экрана — заметка. Весь UI — обрамление, готовое исчезнуть.
2. **Одна рука, две секунды.** Ключевые действия (новая заметка, поиск) достижимы большим пальцем за ≤2 тапа.
3. **Спокойствие.** Никаких красных бейджей, пульсаций, конфетти. Анимации — мягкие, 200–300 мс, ease-out.
4. **Плотность по требованию.** По умолчанию — воздух; настройка компактного режима для power-users.
5. **Тьма как первый класс.** Тёмная тема проектируется одновременно со светлой, не конвертируется.

## 3. Визуальный язык

### 3.1. Палитра (согласовать с брендбуком КОМПАС)

- Основа: тёплые нейтральные (бумага: #FAF9F6-диапазон светлая / глубокий графит, не чёрный, тёмная).
- Один акцентный цвет семейства КОМПАС для интерактивных элементов; допускается персонализация акцента пользователем (5–7 пресетов, спокойные).
- Функциональные цвета — приглушённые; ошибки не кричат.
- Подсветка синтаксиса кода — пастельная, в тон темы.

### 3.2. Типографика

- Основной шрифт заметки: гуманистический sans с отличной кириллицей (кандидаты: Inter, Golos Text, IBM Plex Sans; для «бумажного» режима — serif-опция, напр. Source Serif / PT Serif).
- Моноширинный для кода и raw-markdown: JetBrains Mono.
- Настройки пользователя: размер (5 ступеней), межстрочный интервал, ширина колонки, serif/sans.
- Типографская вёрстка markdown: заголовки различаются размером и насыщенностью, не цветом; маркеры списков — деликатные; чекбоксы — фирменные, с мягкой анимацией отметки.

### 3.3. Форма

- Радиусы 10–14, тонкие разделители вместо карточек-теней, elevation только для модальных слоёв.
- Иконки: единый набор, тонкая линия 1.5–1.75pt (Phosphor/Lucide-класс или кастом семейства КОМПАС).

## 4. Структура приложения и ключевые экраны

Спроектировать все экраны ниже для: **Android phone (390×844 базово), Android tablet / Windows / Web (двух- и трёхпанельный layout, брейкпоинты 600 / 900 / 1200)**.

### 4.1. Каркас

- **Mobile:** один столбец, навигация: список заметок ⟷ заметка; библиотека (папки/теги) — выезжающая панель слева; поиск и «+» — постоянно доступны (нижняя зона).
- **Tablet/Desktop:**三 панели: Библиотека (сворачиваемая) | Список заметок | Редактор. Режим фокуса: только редактор.

### 4.2. Экраны (полный список для дизайна)

1. **Онбординг (3 экрана максимум):** ценность → выбор хранения (Локально / Своё облако / Облако КОМПАС — карточки с честным объяснением) → готово. Без регистрации для локального режима!
2. **Список заметок:** заголовок, сниппет 2 строки, дата, пиктограммы (📎 вложение, 🔒 шифр — своими иконками), закреплённые сверху. Свайпы: закрепить / в архив. Пустое состояние — тёплое, с одной кнопкой.
3. **Редактор** — главный экран, максимум внимания:
   - Live-preview markdown (стилизация на лету, синтаксис-символы проявляются у курсора).
   - Тулбар форматирования над клавиатурой (mobile) — одна строка, самое частое: H, B, I, список, чекбокс, фото, ещё…
   - Заголовок = первая строка (H1 автоматически).
   - Теги — инлайн `#тег` с автодополнением + отображение в шапке.
   - Панель «Инфо»: даты, статистика, backlinks, вложения, экспорт, шифрование.
   - Raw-режим (переключатель).
   - Режим фокуса: скрыть всё, затемнить всё кроме текущего абзаца (опция).
4. **Библиотека:** Все заметки / Закреплённые / папки (дерево) / теги (дерево) / Архив / Корзина. Счётчики — деликатные.
5. **Поиск:** полноэкранный, мгновенные результаты с подсветкой, чипы-фильтры (тег, папка, дата, has:…), недавние запросы.
6. **Backlinks-панель** в заметке.
7. **Шифрование:** флоу установки пароля, разблокировка (пароль/биометрия), состояние «заперто» заметки в списке и в редакторе — спокойное, не «тревожный замок».
8. **Синхронизация/хранилище (настройки):** статус синка (тихий: маленькая метка, детали по тапу), подключение WebDAV/Яндекс.Диск, экран конфликта версий (показ двух версий, но по умолчанию «мы уже объединили, вот история»).
9. **Настройки:** внешний вид (тема, шрифт, ширина), редактор, синхронизация, безопасность, экспорт/импорт (из Bear, Obsidian, Notion, Evernote!), подписка.
10. **Paywall ЗАПИСКИ+:** спокойный, одна страница, честное сравнение, без dark patterns и таймеров.
11. **Публикация по ссылке (P1):** превью публичной страницы заметки — отдельный красивый шаблон «статьи».
12. **Виджеты Android:** быстрая заметка (1×1), последние заметки (2×2), закреплённая заметка (2×2).
13. **Share-target / быстрый ввод:** маленькое модальное окно «в какую заметку/новая».

### 4.3. Состояния

Для каждого экрана: обычное / пустое / загрузка (скелетоны, без спиннеров где можно) / оффлайн / ошибка синка / заперто шифрованием.

## 5. Взаимодействие и микродетали

- Новая заметка: FAB или хоткей → курсор уже в тексте, клавиатура открыта. Ноль промежуточных экранов.
- Автосохранение всегда; понятие «сохранить» отсутствует в UI.
- Жесты mobile: свайп назад, свайп по заметке в списке, pull-to-search (как в Things).
- Windows: полноценные хоткеи (Ctrl+N, Ctrl+P/K — палитра команд, Ctrl+E — raw), палитра команд как у современных редакторов.
- Хэптика Android: деликатная, на чекбоксах и завершении действий.
- Курсорные анимации проявления markdown-синтаксиса — фирменная деталь, проработать отдельно.

## 6. Доступность

WCAG 2.1 AA: контраст 4.5:1+, touch-targets ≥44dp, полная поддержка TalkBack/скринридеров, масштабирование шрифта ОС до 200% без поломки layout, режим сниженной анимации.

## 7. Deliverables

1. Дизайн-система: токены (цвет, типографика, spacing, радиусы, elevation, motion), компоненты (кнопки, поля, списки, чипы, тулбар редактора, модалки, тосты), light+dark.
2. Все экраны из §4.2 в трёх форм-факторах (phone / tablet / desktop-web), ключевые — со состояниями из §4.3.
3. Прототип 2 флоу: «первая заметка за 60 секунд» (онбординг → заметка → фото → тег) и «шифрование + разблокировка».
4. Спецификация редактора: рендеринг каждого markdown-элемента (эталонная «заметка-витрина» со всеми элементами) в light/dark, 3 размерах шрифта, serif/sans.
5. Иконка приложения (Android adaptive + Windows + favicon) в стилистике семейства КОМПАС/МОМЕНТЫ.
6. Шаблон публичной страницы публикации (P1).

## 8. Definition of Done для дизайна

- Любой экран узнаваем как семейство КОМПАС без логотипа.
- Редактор-витрина не уступает Bear по субъективной красоте в слепом сравнении (протестировать на 5–8 пользователях).
- Ни одного экрана, где текст заметки занимает <80% площади в режиме чтения/письма.
- Тёмная тема проверена на OLED (истинные тёмные, без грязных серых заливок).
