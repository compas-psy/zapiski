# BEHAVIOR — функциональная спецификация

**Назначение.** Устранить разночтения при реализации. Здесь описано поведение каждого интерактивного элемента: триггер → результат → крайние случаи → отмена. Где поведение не описано ни здесь, ни в `SCREENS.md` — реализующий **обязан спросить**, а не решить самостоятельно.

Приоритет документов при конфликте: `BEHAVIOR.md` > `SCREENS.md` > `DESIGN_TOKENS.md` > `README.md`.

Сокращения: **ТП** — тактильная подсказка (хэптика); **Т** — тост; **ОО** — отменяемая операция.

---

## 0. Сквозные правила

**Автосохранение.** Debounce 500 мс после последнего кейстрока + принудительно на blur, сворачивание приложения, навигацию назад, закрытие. Слова «Сохранить» в UI нет нигде. Индикатора «сохраняется…» нет — только «изменено только что» в статус-строке.

**Отмена (undo) действий над заметками.** Любая деструктивная или структурная операция (удаление, архивация, перемещение, объединение, снятие шифрования) — **ОО**: показывается тост с кнопкой «Отменить», живёт **6 секунд**, отменяет операцию целиком. Тост не блокирует ввод. Одновременно виден один тост; новый вытесняет предыдущий, вытесненная операция считается подтверждённой.

**Диалоги подтверждения** разрешены ровно в трёх местах: очистка корзины, снятие шифрования, отвязка облачного аккаунта. Везде остальное — ОО-тост.

**Хэптика (Android).** Лёгкий импульс: отметка чекбокса, срабатывание свайпа, успешная разблокировка, срабатывание long-press. Средний: удаление/архивация. Хэптики нет: скролл, набор текста, переключение вкладок.

**Фокус и клавиатура.** Открытие новой заметки: клавиатура поднимается сразу, курсор в конце заголовка. Открытие существующей: клавиатура **не** поднимается, курсор ставится по тапу в текст (в позицию тапа).

**Обработка ошибок.** Ошибка никогда не блокирует ввод текста. Сетевые ошибки — только в статусе синка и разделе настроек, не модалками. Полный реестр текстов — §11.

**Состояние прокрутки.** Позиция скролла списка и позиция курсора в заметке сохраняются на сессию и переживают перезапуск приложения (хранится в `.zapiski/config.json`, не в `.md`).

## 1. Список заметок

### 1.1. Строка заметки

| Триггер | Результат |
| --- | --- |
| Тап | Открыть заметку. Mobile — push-переход 250 мс; desktop — заменить содержимое панели редактора |
| Long-press (500 мс) | ТП + контекстное меню: Закрепить/Открепить · Дублировать · Переместить · Зашифровать · Экспорт · В архив · Удалить |
| Свайп вправо | Закрепить/Открепить |
| Свайп влево | В архив |
| Тап при активном поиске | Открыть заметку, подсветка совпадений сохраняется, скролл к первому |

**Механика свайпа.** Порог срабатывания 96 px или скорость >0.8 px/мс. До порога — иконка и подложка проявляются пропорционально смещению (opacity 0→1 на отрезке 0–96). После порога — иконка фиксируется, добавляется ТП. Отпускание до порога — возврат 200 мс ease-out, ничего не происходит. Отпускание после — действие + строка сворачивается по высоте за 200 мс (для архивации) или перескакивает в секцию «Закреплённые» (для закрепления, анимация перемещения 250 мс).

**Крайние случаи.** Уже закреплённая заметка: свайп вправо открепляет, иконка и текст подложки меняются на «Открепить». Заметка в архиве: свайп влево — «Вернуть из архива». Зашифрованная заметка: свайпы работают (закрепление/архивация не требуют расшифровки), long-press-меню скрывает «Экспорт» и «Дублировать».

**Архивация — ОО**: тост «Заметка в архиве · Отменить».

### 1.2. Секции и сортировка

Порядок: «Закреплённые» (всегда сверху, сортировка — вручную заданный порядок, по умолчанию по дате изменения) → группы по месяцам по дате изменения (текущий месяц назван «АВГУСТ», прошлый год — «АВГУСТ 2025»).

Смена сортировки — в меню «⋯» шапки: по дате изменения (умолч.) / по дате создания / по заголовку А-Я / вручную. Выбор запоминается **на папку**, не глобально.

### 1.3. Виртуализация и производительность

Список виртуализирован при >100 элементов. Высота строки фиксирована для конкретного режима плотности (обычный 74 px, компактный 58 px) — это гарантирует корректный скроллбар без измерения. Догрузка — окно ±20 экранов. Скролл 60 fps на 10 000 заметок обязателен.

### 1.4. Pull-to-search

Оттягивание списка вниз >64 px в позиции скролла 0 открывает полноэкранный поиск с поднятой клавиатурой. До 64 px — поле поиска проявляется пропорционально (opacity + смещение), отпускание возвращает. Жест отключён, когда идёт синк-обновление списка.

## 2. Редактор

### 2.1. Ввод и разметка

**Live-preview.** Символы разметки (`**`, `#`, `>`, `==`, `[[`) всегда занимают место в потоке, меняется только `opacity`: 0 вне активного узла, 1 (`--text-disabled`) когда курсор внутри узла или узел в выделении. Переход 160 мс. **Layout не сдвигается никогда** — это фирменная деталь и главный критерий приёмки редактора.

«Активный узел» = синтаксическое дерево CodeMirror: курсор внутри диапазона узла или примыкает к его границе.

**Автоформатирование при вводе:**

| Ввод | Результат |
| --- | --- |
| `- ` в начале строки | маркированный список |
| `1. ` | нумерованный список |
| `- [ ] ` или `[] ` | чекбокс |
| `# ` … `###### ` | заголовок уровня |
| `> ` | цитата |
| `\`\`\`язык` + Enter | код-блок с подсветкой |
| `---` + Enter | разделитель |
| `#` + буква | открыть автодополнение тегов |
| `[[` | открыть автодополнение заметок |

**Enter в списке:** создаёт следующий элемент того же типа. Enter на пустом элементе списка — выходит из списка (снимает маркер). Tab/Shift+Tab — вложенность списка (до 6 уровней).

**Backspace в начале элемента списка** — снимает маркер, не удаляя строку.

**Умная вставка (paste):** HTML из буфера конвертируется в markdown (заголовки, списки, жирный/курсив, ссылки, таблицы); картинка из буфера копируется в `attachments/` и вставляется как `![](attachments/…)`; ссылка, вставленная поверх выделенного текста, оборачивает его в `[текст](url)`; обычный текст вставляется как есть. Ctrl+Shift+V — вставить без форматирования.

**IME/кириллица.** Композиция IME никогда не прерывается декорациями: перерисовка live-preview откладывается до `compositionend`. Автозамена, свайп-ввод и диктовка ОС обязаны работать без «символов-призраков» — это регрессионный тест-кейс №1.

### 2.2. Заголовок

Заголовок заметки = первая строка файла. Отдельного поля нет. Если первая строка начинается с `# ` — это H1 и заголовок; если нет — первая непустая строка становится заголовком в списке, но в тексте остаётся обычным абзацем.

**Переименование файла.** Имя файла синхронизируется с заголовком с задержкой 2 с после прекращения правки первой строки. Запрещённые в ФС символы (`/ \ : * ? " < > |`) заменяются на `-`. Коллизия имён — суффикс ` 2`, ` 3`. Если файл переименован, **все wiki-ссылки на него в vault обновляются автоматически** (транзакционно: либо все, либо ни одной), пользователю — тост «Обновлено ссылок: N».

### 2.3. Чекбоксы

Тап по квадрату — переключение. Тап по тексту — постановка курсора (не переключение). Анимация: заливка 200 мс ease-out, галочка рисуется `stroke-dashoffset` 160 мс, текст уходит в `--text-secondary` + `line-through` за 200 мс. ТП лёгкая.

Отмеченные чекбоксы **не перемещаются и не скрываются** автоматически. Настройка «переносить выполненные вниз» — выключена по умолчанию.

### 2.4. Теги

Автодополнение открывается на `#` + минимум 1 символ. Список: до 8 совпадений, сортировка по частоте использования, вложенные теги показываются целиком (`практика/супервизия`). Enter/Tab — подставить, Esc — закрыть, стрелки — навигация. Пробел завершает тег.

Тег в тексте кликабелен: тап → поиск по этому тегу. Чипы в шапке — отражение тегов из текста, редактируются только через текст (тап по чипу — тоже поиск). Удаление тега из текста убирает чип.

### 2.5. Wiki-ссылки

`[[` открывает поиск по заголовкам заметок (fuzzy, до 8 результатов, первым — точное совпадение). Enter — вставить. Если совпадений нет и пользователь дописал имя вручную — ссылка «висячая»: рендерится акцентом с пунктиром 50% opacity; тап предлагает «Создать заметку „Имя“».

Тап по существующей ссылке — переход. Long-press / Ctrl+клик — открыть в соседней панели (desktop) или предпросмотр-поповер (mobile).

### 2.6. Вложения

Вставка фото: выбор из галереи или камера → файл копируется в `attachments/` с именем `ГГГГ-ММ-ДД_хеш.ext` → вставляется `![](attachments/…)`. Показ прогресса — инлайн-плейсхолдер `--surface` с процентом, при ошибке — «Не удалось вставить · Повторить».

Изображение в тексте рендерится с max-width колонки, радиус 12. Тап — полноэкранный просмотр (свайп вниз закрывает). Long-press — меню: Заменить · Экспортировать · Удалить.

Удаление ссылки на изображение из текста **не удаляет файл** из `attachments/`. Осиротевшие вложения чистятся вручную в Настройки → Хранилище → «Найти неиспользуемые вложения».

### 2.7. Тулбар (mobile)

Появляется вместе с клавиатурой, высота 44, прижат к ней. Кнопки применяют формат к выделению или переключают режим ввода на позиции курсора. «H» — циклическое переключение H1→H2→H3→обычный. «⋯» открывает вторую строку: цитата, код, таблица, разделитель, ссылка, сноска, wiki-ссылка.

При отсутствии выделения B/I вставляют парные маркеры и ставят курсор между ними.

### 2.8. Режим фокуса

Вход: меню «⋯» → «Фокус» или Ctrl+Shift+F. Выход: Esc или тап по подсказке. Абзац считается активным, если в нём курсор; остальные — opacity 28%, переход 300 мс. При `prefers-reduced-motion` — без перехода. Скролл сохраняет активный абзац в вертикальном центре (typewriter scrolling) — **опция**, по умолчанию выключена.

### 2.9. Панель «Инфо»

Содержимое: даты создания/изменения, статистика (слова, знаки, время чтения), список вложений, backlinks, действия (Экспорт, Зашифровать, Дублировать, Переместить, Удалить), путь к файлу (моно, тап — копировать). На mobile — bottom sheet, на desktop — правая панель 280 px.

### 2.10. Backlinks

Панель внизу заметки, сворачиваемая, состояние запоминается. Считаются `[[wiki]]` и обычные markdown-ссылки на файл. Обновляется индексом асинхронно, ≤300 мс после сохранения источника. Если ссылок нет — панель не показывается вовсе (не «0 ссылок»).

## 3. Библиотека

Открытие: свайп от левого края, тап по бургеру, Ctrl+\\. Закрытие: свайп влево, тап по скриму, Esc, выбор раздела. Анимация 250 мс ease-out, скрим появляется параллельно.

**Дерево папок.** Шеврон разворачивает/сворачивает, состояние узлов запоминается. Тап по названию — выбрать папку (фильтр списка), не разворачивая. Long-press — меню: Новая подпапка · Переименовать · Переместить · Удалить.

**Удаление папки** — единственное место, где спрашивается уточнение: «Удалить папку и N заметок?» с выбором «Только папку (заметки — в родительскую)» / «Папку с заметками (в корзину)».

**Дерево тегов** строится из текстов заметок и **не редактируется напрямую**: переименование тега (long-press → «Переименовать») выполняет замену во всех заметках — ОО с тостом «Переименовано в N заметках · Отменить».

**Счётчики** обновляются реактивно, показывают количество не-архивных заметок. У «Корзины» счётчик — количество элементов; пустая корзина счётчик не показывает.

**Drag-and-drop** (desktop): заметку из списка можно перетащить на папку в дереве — перемещение файла на ФС + обновление ссылок. Подсветка цели — рамка 1.5 акцентом.

## 4. Поиск

**Ввод.** Результаты обновляются с debounce 120 мс. Пустой запрос — показывать «НЕДАВНИЕ» (последние 8 запросов) и «ПОСЛЕДНИЕ ОТКРЫТЫЕ» (5 заметок). Запрос короче 2 символов — не искать.

**Операторы:** `tag:практика` · `folder:Личное` · `before:2026-08-01` · `after:вчера` · `has:image|file|todo|link` · `"точная фраза"` · `-исключение`. Ввод оператора предлагает автодополнение значений. Чипы-фильтры — визуальный эквивалент операторов: тап по чипу дописывает оператор в строку, удаление чипа убирает его из строки. Строка и чипы всегда синхронны.

**Результаты.** Ранжирование: совпадение в заголовке > в тексте; свежесть при равенстве. Показывать до 3 фрагментов на заметку с ±40 символами контекста. Подсветка всех вхождений. Ограничение выдачи 200, дальше — ленивая догрузка.

**Зашифрованные заметки** не индексируются: показываются в конце выдачи только при совпадении с именем-плейсхолдером, с подписью «зашифровано — содержимое не ищется».

**Поиск в заметке** (Ctrl+F): узкая панель поверх редактора, счётчик «3 из 12», Enter/Shift+Enter — переходы, Esc — закрыть с сохранением позиции. Замена — Ctrl+H, с подтверждением для «Заменить всё» (ОО).

**Пустой результат:** «Ничего не нашлось» + подсказка снять один из фильтров (перечислить активные) — не абстрактное «попробуйте иначе».

## 5. Шифрование

### 5.1. Установка

Валидация пароля: минимум 8 символов; индикатор силы — три деления, приглушённые цвета, без «слабый/плохой». Несовпадение повтора показывается только после blur второго поля. Кнопка «Зашифровать» неактивна, пока условия не выполнены.

После подтверждения: файл перезаписывается в `.md.enc` атомарно (tmp + rename), исходный `.md` затирается и удаляется, запись убирается из FTS-индекса, локальные версии за период до шифрования удаляются. Прогресс — если >300 мс.

**Биометрия** предлагается сразу тумблером. Ключ кладётся в Android Keystore / Windows Hello / WebAuthn-PRF. Если платформа не поддерживает — тумблер скрыт (не «выключен и недоступен»).

### 5.2. Разблокировка

Тап по запертой заметке → биометрия автоматически, если включена; иначе — поле пароля. Успех — ТП + переход к содержимому 200 мс.

**Неверный пароль:** точки мягко возвращаются в исходное состояние (200 мс, без тряски и красного), подпись `--text-secondary` «Пароль не подошёл», ниже — подсказка, если задана. Попытки 1–4 без задержки. После 5-й — 30 с задержки с обратным отсчётом в подписи; после 8-й — 5 мин. Счётчик сбрасывается при успехе. **Данные не удаляются никогда, устройство не блокируется.**

**Отмена биометрии** пользователем — не ошибка: показать поле пароля без сообщений.

### 5.3. Открытая заметка и автозамок

Расшифрованное содержимое живёт только в памяти. Автозамок: 10 мин бездействия (настраивается 1/5/10/30 мин / до выхода). Таймер сбрасывается любым вводом или скроллом. Немедленный замок: сворачивание приложения, блокировка экрана, тап по замку в шапке, выход из заметки.

При сворачивании — `FLAG_SECURE`: содержимое не попадает в превью задач и скриншоты.

За 30 с до автозамка — чип меняет текст на «Закроется через 30 секунд» (без модалки). Любой ввод отменяет.

**Снятие шифрования** — диалог подтверждения (одно из трёх мест): «Заметка станет обычным файлом на диске. Продолжить?».

### 5.4. Синк зашифрованных заметок

`.md.enc` синхронизируются как обычные бинарные файлы. Конфликт зашифрованной заметки не может быть разрешён автослиянием — сохраняются обе версии: «Дневник» и «Дневник (конфликт, устройство Windows)», пользователю тост с объяснением. Это единственный случай, когда пользователь видит две версии.

## 6. Синхронизация — поведение в UI

**Индикатор** (точка 6 px в шапке): success — синхронизировано; акцент, медленно проявляется/гаснет 1.2 с — идёт синк; `--text-tertiary` — оффлайн; warning — ошибка. Тап по индикатору → панель статуса: последняя синхронизация, количество заметок, объём, кнопка «Синхронизировать сейчас», при ошибке — её текст и «Повторить».

**Частота:** при старте приложения, при возврате из фона, после сохранения (debounce 5 с), по pull-to-refresh в списке, по кнопке. Websocket — для KompasCloud (мгновенно).

**Конфликты.** Автослияние по умолчанию; тост «Версии объединены · История» (живёт 6 с, не ОО — отменять нечего). Экран выбора версии отсутствует. История версий: список снапшотов с датой и источником, превью diff (добавления — фон success 16%, удаления — danger 16% + зачёркивание), кнопка «Восстановить эту версию» — ОО.

**Оффлайн.** Чип в шапке списка. Всё редактирование доступно. Очередь изменений сохраняется на диск и переживает перезапуск. При возврате сети — автосинк без уведомления, если конфликтов нет.

## 8. Виджеты, share-target, быстрый ввод

**Быстрая заметка (1×1).** Тап открывает приложение сразу в новой заметке с клавиатурой. Виджет показывает иконку пера на `--surface`, подпись «Записать».

**Последние (2×2).** До 4 заголовков (15 px, 1 строка, ellipsis) + дата моно. Тап по строке — открыть заметку; тап по шапке — открыть список; иконка «+» в углу — новая заметка. Обновление — при изменении данных, не по таймеру. Зашифрованные — как «Зашифровано» без содержимого.

**Закреплённая (2×2).** Одна выбранная заметка: заголовок + первые ~6 строк. Чекбоксы **интерактивны прямо в виджете** (тап отмечает, ТП). Зашифрованную выбрать нельзя.

**Виджеты уважают системную тему** и выбранный акцент.

**Share-target.** Модалка (bottom sheet): превью содержимого (текст/ссылка/картинка), выбор «Новая заметка» (по умолчанию) или поиск существующей, выбор папки, кнопка «Добавить». Для ссылки подставляется `[заголовок](url)`, если удалось получить title за 2 с, иначе голый url. Закрывается сразу после добавления, приложение не открывается; тост «Добавлено в „Заметка“ · Открыть».

**Quick Settings tile** — эквивалент быстрой заметки.

## 9. Импорт и экспорт

**Импорт.** Мастер: выбор источника → выбор файла/папки → предпросмотр («Найдено: 1 240 заметок, 380 вложений, 12 папок») → выбор целевой папки → импорт с прогрессом (отменяемым) → отчёт («Импортировано 1 240 · Пропущено 3 — показать»).

Правила: Obsidian-vault импортируется как есть, включая `attachments` и frontmatter; коллизии имён — суффикс; неподдерживаемое содержимое (Notion-БД, Evernote-таблицы сложной вёрстки) конвертируется в markdown-таблицу или, при невозможности, сохраняется как приложенный файл и упоминается в отчёте. **Импорт никогда не перезаписывает существующие заметки.**

**Экспорт.** Одна заметка: md / PDF / HTML / DOCX. Несколько: zip с сохранением структуры папок и `attachments`. Экспорт PDF использует текущую тему? — **нет**: всегда светлая «Бумага», колонка 640, без интерфейсных элементов. Зашифрованная заметка экспортируется только после разблокировки.

## 10. Настройки — поведение

Все изменения применяются **мгновенно**, без кнопки «Применить». Смена темы/акцента — кроссфейд 200 мс, без белой вспышки. Смена шрифта или плотности перерисовывает превью-заметку в разделе «Внешний вид» вживую.

**Сброс настроек** — в конце раздела, с подтверждением; не затрагивает заметки.

**Хранилище:** показать путь к vault, размер, количество файлов, кнопки «Открыть папку», «Сменить папку» (с предупреждением о переносе), «Найти неиспользуемые вложения», «Перестроить индекс» (безопасно, индекс — производная).

**Аккаунт:** при отсутствии — «Аккаунт не нужен для локальной работы» + кнопка входа. При наличии — email/Яндекс ID, тариф, «Выйти» (подтверждение: локальные заметки останутся).

## 13. Приёмочные критерии поведения (проверяются вручную)

1. От тапа по иконке приложения до курсора в новой заметке — **<2 с** на среднебюджетном Android.
2. Ни одно действие пользователя не приводит к безвозвратной потере текста: любой деструктив отменяем 6 с или лежит в корзине 30 дней.
3. Разметка у курсора проявляется **без единого сдвига layout** — проверяется покадрово на записи экрана.
4. Свайп, отпущенный до порога, никогда не выполняет действие.
5. Ни одно сообщение об ошибке не блокирует ввод текста.
6. Переименование заметки с 20 входящими ссылками обновляет все 20 или ни одной.
7. Автозамок срабатывает ровно по таймеру и немедленно при сворачивании; в превью задач содержимого нет.
8. Все хоткеи из §7 работают и отражены в палитре команд.
9. При `prefers-reduced-motion` ни одна анимация не проигрывается, функциональность полная.
10. Каждая ячейка матрицы §12 воспроизводима в отладочном меню.
