## 1. Заголовок заметки — отдельное поле

**Что не так.** Заголовок вычисляется из первой строки текста. В спецификации это было написано неаккуратно, и получилось, что отдельного поля нет вовсе: пользователь не понимает, где кончается название и начинается текст, а в списке оказывается случайный обрывок («Доработки:»).

**Как надо.** Заголовок — **самостоятельное однострочное поле** в самом верху редактора, всегда видимое, до тела заметки.

- Плейсхолдер: «Название заметки» цветом `--text-tertiary`.
- Типографика: H1 редактора (mobile 24/700/−.02em, desktop 30/700/−.02em). Разметка внутри поля не работает: `**` останется звёздочками.
- Enter в заголовке переводит курсор в начало тела, не создаёт перенос.
- Backspace в начале тела при пустом заголовке поднимает курсор в заголовок.
- Tab из заголовка — в тело.

**Связь с файлом (важно, это про file-over-app).** Заголовок хранится первой строкой файла в виде `# Название`. Тело начинается со следующей непустой строки и этот H1 не содержит.

- Файл без H1 в первой строке: заголовок пустой, при первом вводе строка `# …` создаётся сверху.
- Файл с текстом до первого H1 (чужой vault): заголовок пустой, текст остаётся телом. Ничего не переносим и не переписываем.
- Имя файла синхронизируется с заголовком по правилам `BEHAVIOR.md` §2.2 (задержка 2 с, транслитерация запрещённых символов, обновление wiki-ссылок).
- **Пустой заголовок разрешён.** В списке такая заметка показывается как «Без названия» цветом `--text-tertiary`, а не первой строкой тела.

В строке списка: заголовок — из поля, сниппет — из тела. Сейчас сниппет дублирует заголовок, потому что и то и другое берётся из текста; после правки дублирования быть не должно.

## 2. Локализация: приложение открывается на английском

**Что не так.** Windows-сборка стартует на английском: «All notes», «Pinned», «FOLDERS», «New folder», «just now · 67 words».

**Как надо.**

- Язык по умолчанию — **русский**, независимо от локали ОС. Английский доступен переключателем в настройках. Обратный порядок (следовать ОС) неверен: продукт русскоязычный.
- Ни одной строки, зашитой в компонент. Все — в каталогах `ru.json` / `en.json`.
- **Относительное время — через `Intl.RelativeTimeFormat` с русскими правилами склонения**, а не строкой «5 minutes ago»: «только что», «5 минут назад», «вчера», «5 авг».
- **Счётчик слов склоняется:** 1 слово · 2 слова · 5 слов · 67 слов. Английская форма «67 words» недопустима.
- Даты: «5 авг», «5 августа 2025» — месяц строчными, без точки.
- Проверка приёмки: поиск по собранному бандлу не находит ни одной из строк «All notes», «Pinned», «New folder», «words», «ago».

Словарь для сверки: All notes → **Все заметки**; Pinned → **Закреплённые**; Folders → **Папки**; Tags → **Теги**; New folder → **Новая папка**; Archive → **Архив**; Trash → **Корзина**; Settings → **Настройки**; Search → **Поиск**.

## 3. Настройки: включить всё, что объявлено

**Что не так.** Часть настроек не подключена — например, ширина колонки редактора не меняет ничего.

**Как надо.** Каждая настройка применяется **мгновенно**, без кнопки «Применить» и без перезапуска, и переживает перезапуск. Настройка, которую нельзя подключить в эту итерацию, из интерфейса **убирается** — неработающий переключатель хуже отсутствующего.

Обязательный аудит. Для каждой строки — проверить, что она действительно меняет то, что обещает:

**Внешний вид**
- Тема: Системная / Бумага / Крем / Мел / Графит / Чернила — кроссфейд 200 мс, без белой вспышки.
- Акцент: шесть пресетов, применяется ко всем поверхностям сразу.
- Размер текста: 5 ступеней (14 / 15 / 16 / 18 / 20) — множитель над базовым токеном.
- Интерлиньяж: 1.45 / 1.65 / 1.85.
- **Ширина колонки редактора: 640 / 720 / вся ширина** — сейчас не работает, это главный пример.
- Шрифт: Golos/Geist ↔ Source Serif.
- Компактный режим: высота строки списка 74 → 58.

**Редактор**
- Режим: простой / профессиональный (см. §9).
- Панель форматирования: показывать всегда / только при выделении / скрыть (см. §4).
- Автосохранение: индикатор в статус-строке.
- Проверка орфографии.
- Перенос выполненных задач вниз (по умолчанию выключено).

**Вложения** (новое, см. §5) · **Синхронизация** · **Безопасность** · **Экспорт и импорт**.

Приёмочный тест на каждую: изменить значение → увидеть эффект без перезагрузки → перезапустить приложение → значение сохранилось.

## 4. Панель форматирования

**Что не так.** Форматировать можно только markdown-разметкой руками. Для простого режима (§9) это неприемлемо, да и в профессиональном панель нужна.

**Как надо.** Панель — **наша**, в токенах СИМПАСА. Референс, который вы прислали, задаёт *паттерн* (плавающие пилюли с выпадающими меню), но не внешний вид: иконки, радиусы, цвета и тени берём свои.

### Расположение

- **Desktop:** пилюля, приклеенная под шапкой редактора, по центру колонки текста. При скролле остаётся на месте.
- **Mobile:** та же пилюля прижата к верхней кромке клавиатуры (заменяет нынешний тулбар высотой 44).
- Настройка «показывать всегда / только при выделении / скрыть».

### Форма

Три группы в одной строке, между группами зазор 10:

```
[ ↶  ↷ ]   [ Aa │ B │ ☰▾ │ ⊞ │ 🔗 │ 📎▾ │ Σ ]   [ ☺ ]
```

- Контейнер группы: высота 44, радиус `--r-full`, фон `--surface`, рамка 1 px `--line`, тень `--shadow-card`.
- Кнопка: 36×36, радиус 10, иконка 19, stroke 1.75, цвет `--text-secondary`.
- Hover — фон `--surface-alt`; активное состояние (формат применён к выделению) — фон `--accent-soft`, иконка `--accent-on-soft`; press — `scale(.97)`.
- Разделители внутри группы — хайрлайн `--line` высотой 20, не отступы.

### Меню

Выпадают вниз с якорем у кнопки, радиус `--r-card`, тень `--shadow-pop`, появление 160 мс: fade + 6 px снизу, `transform-origin` у кнопки. Строка меню: иконка 18 + название + хоткей моно 11 `--text-tertiary` справа. Esc закрывает и возвращает фокус в текст.

| Кнопка | Меню |
| --- | --- |
| **Aa** — стиль абзаца | Заголовок ▸ (H1–H6) · Текст · Цитата · Выноска · Код · Мелкий текст · Разделитель. Текущий стиль помечен галочкой |
| **B** — начертание | без меню: жирный `Ctrl+B`; долгое нажатие/правый клик — курсив, зачёркнутый, подсветка, моно |
| **Списки** | Без списка · Список с маркерами · Список с номерами · Чек-лист · Сворачиваемый блок. Текущий тип помечен галочкой |
| **Таблица** | без меню: вставляет 3×3 с шапкой, курсор в первую ячейку. Дальше правится ручками строк и столбцов |
| **Ссылка** | без меню: диалог «Текст» + «Адрес»; при выделенном тексте поле «Текст» предзаполнено |
| **Вложение** | Изображение · Файл · Аудиозапись (см. §5) |
| **Σ формула** | Ввод LaTeX с живым превью — на mobile полем над клавиатурой, на desktop диалогом. **Опционально:** включать только если KaTeX уже в сборке |
| **☺ эмодзи** | Палитра. Смысл — вставка в текст пользователя, это не UI-эмодзи, запрет системы не нарушается |

### Устройство меню — уточнение по референсам

Присланные снимки Telegram задают **паттерн взаимодействия**, и он хороший. Забираем механику, рисуем своим: фон `--surface`, радиус `--r-card`, тень `--shadow-pop`, строка меню 40 px, иконка 18 слева, хоткей моно 11 `--text-tertiary` справа.

**1. Текущее состояние отмечено галочкой.** В каждом меню, где выбирается один вариант из набора (стиль абзаца, тип списка), активный пункт помечен галочкой 16 px цветом `--accent` у правого края. Пункт «Текст» и «Без списка» — это полноценные варианты выбора, а не отсутствие действия.

**2. Кнопка панели подсвечена, пока её меню открыто** — фон `--accent-soft`, иконка `--accent-on-soft`. Закрылось меню — подсветка снялась.

**3. Меню «Стиль абзаца» (Aa)**

| Пункт | Примечание |
| --- | --- |
| Заголовок | ведёт во вложенное меню, шеврон справа |
| Текст | вариант по умолчанию, `Ctrl+0` |
| Цитата | `Ctrl+Shift+Q` |
| Выноска | крупная врезка внутри текста |
| Код | `Ctrl+Shift+C` |
| Мелкий текст | 13 px, для сносок и подписей |
| Разделитель | вставка, не стиль — отделён хайрлайном снизу |

**4. Вложенное меню заголовков** открывается **на месте родительского**, а не рядом. Сверху строка «← Назад» с хайрлайном под ней, дальше H1–H6. **Каждый пункт набран своим реальным кеглем и весом** — пользователь видит результат, а не читает название. Слева индекс `H₁…H₆` моноширинным `--text-secondary`.

Возврат: «Назад», свайп вправо (mobile), Esc (desktop).

**5. Меню списков**

Без списка (по умолчанию) · Список с маркерами · Список с номерами · Чек-лист · Сворачиваемый блок.

«Сворачиваемый блок» — заголовок со стрелкой и скрытым содержимым; в файле сохраняется как `<details><summary>`.

**6. Формула LaTeX — разное поведение на платформах**

- **Mobile:** модалки нет. Над клавиатурой появляется поле «Формула LaTeX» (высота 56, радиус `--r-full`, фон `--surface-sunken`) и под ним кнопка «Готово» на всю ширину. Формула в тексте перерисовывается по мере ввода — превью и есть результат.
- **Desktop:** диалог 480 с полем, флажком «Отдельной строкой» и областью превью `--surface-sunken`; кнопки «Отмена» и «Вставить».
- Ошибка синтаксиса не блокирует ввод: превью показывает последнюю корректную версию, под полем строка `--danger-text` «Не удалось разобрать формулу».

**7. Таблица — ручки строк и столбцов**

Это самая недооценённая часть, без неё таблица нередактируема на телефоне.

- При установке курсора в ячейку активные строка и столбец получают рамку 1.5 `--accent`.
- На внешней границе строки (слева) и столбца (сверху) появляется **ручка**: скруглённая плашка 14×34 (для столбца — 34×14) цветом `--accent` с тремя точками `--on-accent`. Ручка — зона нажатия ≥44 px.
- Нажатие на ручку открывает панель из двух частей:

  **Выравнивание** — ряд из шести круглых кнопок 36: по левому краю, по центру, по правому; по верху, по середине, по низу. Отдельная плашка над меню, подпись «Выравнивание» 11 caps `--text-tertiary`.

  **Действия** — обычное меню: Залить строку · Объединить ячейки · Вставить сверху · Вставить снизу · **Удалить строку** (`--danger-text`, иконка того же цвета, последним пунктом за хайрлайном).

  Для столбца — те же пункты в терминах столбца: Залить столбец · Объединить ячейки · Вставить слева · Вставить справа · Удалить столбец.

- Перетаскивание ручки меняет порядок строк и столбцов; при переносе — подсветка целевой позиции линией 2 px `--accent`.
- Удаление строки и столбца — **ОО**: тост «Строка удалена · Отменить».

**8. Заголовок таблицы.** Первая строка — шапка (фон `--surface-sunken`, вес 600). Переключатель «Строка заголовка» — в меню ручки столбца.

### Поведение

- Действие применяется к выделению; без выделения — переключает режим ввода на позиции курсора (парные маркеры, курсор между ними).
- Кнопки отражают состояние текста под курсором: курсор внутри жирного → «B» подсвечена.
- Отмена/повтор — глубина сессии, работают и для действий панели.
- Панель не перехватывает фокус: после нажатия курсор возвращается в текст на ту же позицию.

## 5. Вложения: изображения, файлы, аудио

**Что не так.** Картинки не вставляются, где хранятся — неизвестно, настроить нельзя.

**Как надо.**

### Способы вставки
1. Кнопка «Вложение» на панели (§4).
2. **Ctrl+V** из буфера — изображение из буфера сохраняется как файл.
3. **Drag-and-drop** файла в область текста — подсветка зоны рамкой 1.5 `--accent` и фоном `--accent-soft`.
4. Mobile: камера / галерея / файл / диктофон.

### Куда кладём
Правило по умолчанию — **папка `attachments/` в корне хранилища**, имя файла `ГГГГ-ММ-ДД_хеш.ext`, в текст вставляется **относительная ссылка** `![](attachments/2026-08-11_f5c6e3.png)`.

Настройки → **Вложения** (раздел новый):

| Настройка | Значения | По умолчанию |
| --- | --- | --- |
| Папка вложений | Общая `attachments/` в корне · Рядом с заметкой · Своя папка (выбор пути) | Общая |
| Имена файлов | Дата и хеш · Исходное имя · Дата и исходное имя | Дата и хеш |
| Крупные изображения | Оставлять оригинал · Ужимать до 2048 px | Ужимать |
| Показывать путь под вложением | вкл / выкл | выкл |

Внизу раздела — фактический путь моноширинным и кнопки «Открыть папку» и «Найти неиспользуемые вложения».

### Как выглядит в тексте
- **Изображение:** ширина по колонке, радиус 12. Тап — полноэкранный просмотр, свайп вниз закрывает. Long-press / правый клик — Заменить · Открыть папку · Экспортировать · Удалить ссылку.
- **Файл:** строка-карточка (радиус 12, фон `--surface`, 1 px `--line`, паддинг 12×14): иконка типа 20, имя, размер моно 11 `--text-tertiary`. Клик открывает системным приложением.
- **Аудио:** мини-плеер из `COMPONENTS.md` §8 — кнопка 34, прогресс 3 px, длительность моно. Запись с микрофона кладётся туда же в `.opus`.

### Крайние случаи
- Прогресс копирования — инлайн-плейсхолдер `--surface` с процентом, при ошибке «Не удалось вставить · Повторить».
- Удаление ссылки из текста **не удаляет файл** — чистка только вручную.
- Зашифрованная заметка: вложения шифруются вместе с ней и хранятся внутри контейнера, а не отдельными файлами.
- Нет места на диске — текст сохраняется, вложение нет, сообщение из реестра `BEHAVIOR.md` §11.

## 6. Windows: своя строка заголовка

**Что не так.** Иконка и название приложения показаны дважды — в системной строке заголовка и в левой колонке.

**Как надо.** Окно **безрамочное** (`decorations: false` в Tauri), строку заголовка рисуем сами — как в присланных референсах.

- Высота 40, фон `--surface-alt`, нижняя граница 1 px `--line`, вся полоса — drag-region.
- **Знак и вордмарк ЗАПИСКИ живут только в сайдбаре.** В строке заголовка их нет.
- Слева в строке — кнопка сворачивания сайдбара и, при необходимости, навигация назад/вперёд.
- Справа — свернуть / развернуть / закрыть в стиле Windows: 46×32, hover `--surface-sunken`, закрытие `#C42B1C` с белой иконкой. Кнопки не перетаскивают окно.
- Двойной клик по полосе разворачивает окно, работает системное контекстное меню по правому клику.
- Панель задач и Alt+Tab показывают иконку приложения — этого достаточно, дублировать её в интерфейсе не нужно.

Сайдбар начинается **под** строкой заголовка и повторяет её фон, чтобы граница окна читалась одной плоскостью.

## 7. Теги — привести к дизайну

**Что не так.** `#теги` отображаются не так, как в макетах.

**Как надо** (правило из `DS-ALIGNMENT.md` §10 — плотность добирается воздухом, а не цветом):

- **В тексте заметки:** `#практика/супервизия` — цвет `--accent`, **без подложки и без рамки**, символ `#` того же цвета, но на 60 % непрозрачности. Кликабельно: тап открывает поиск по тегу. Подчёркивания нет.
- **В шапке заметки:** те же теги строкой под заголовком, тоже без заливки, разделитель — пробел 14 px. Это отражение тегов из текста; редактируются только в тексте.
- **Заливку `--accent-soft` получает только активный фильтр** в поиске и в библиотеке — больше нигде.
- **В строке списка теги не показываются вовсе.**
- Автодополнение: до 8 совпадений по частоте, вложенные теги целиком, Enter/Tab подставляет, пробел завершает.
- В дереве библиотеки вложенные теги — дерево с отступом 48, счётчики моно 11 `--text-tertiary`, ноль не печатается.

## 8. Два режима редактора

**Простой** (по умолчанию для новых пользователей)
- Разметка **не видна никогда**: ни `**`, ни `#`, ни `>` — даже под курсором. Текст выглядит как результат.
- Форматирование только панелью (§4) и хоткеями.
- Raw-режим и wiki-ссылки скрыты из интерфейса.
- Вставка markdown из буфера конвертируется в форматирование молча.

**Профессиональный**
- Текущее поведение: разметка проявляется у курсора (`--text-ghost`, 160 мс, **без сдвига layout**), доступен raw `Ctrl+E`, wiki-ссылки, сноски, палитра команд.

Переключатель — Настройки → Редактор. Смена режима **не меняет файл**: это только способ показа. Переключение мгновенное, позиция курсора сохраняется.

При первом запуске спрашивать не нужно — простой режим включён, а в подсказке пустого редактора одна строка: «Разметка Markdown включается в настройках».

## 9. Мелочи, замеченные на скриншотах

- Кнопка «Новая папка» в сайдбаре набрана акцентом и выглядит как активный пункт. По `REBUILD.md` §1.3 это обычный пункт списка с иконкой «+» в общем ритме, цвет `--text-secondary`.
- Иконка скрепки рядом с заголовком в списке — правильно, но она должна стоять **после** заголовка и иметь цвет `--text-tertiary`.
- В строке списка вместо «just now · 67 words» — «только что · 67 слов».

## Приёмка

- [ ] Ни одной английской строки в русском интерфейсе; счётчики и даты склоняются.
- [ ] Заголовок — отдельное поле; сниппет в списке не дублирует его; пустой заголовок даёт «Без названия».
- [ ] Каждая настройка меняет то, что обещает, применяется мгновенно и переживает перезапуск; неподключённых настроек в интерфейсе нет.
- [ ] Изображение вставляется четырьмя способами, файл лежит в настраиваемой папке, путь виден в настройках.
- [ ] Аудиозапись пишется и воспроизводится мини-плеером.
- [ ] В окне Windows название и иконка приложения встречаются один раз.
- [ ] Теги без заливки в тексте и в шапке; заливка только у активного фильтра.
- [ ] В простом режиме ни один символ разметки не виден ни в одном состоянии, включая курсор внутри узла.
- [ ] Панель форматирования не уводит фокус из текста.
- [ ] Текущий стиль абзаца и тип списка отмечены галочкой в своих меню.
- [ ] Заголовки в подменю набраны реальными кеглями H1–H6.
- [ ] Таблица правится с телефона: ручки строк и столбцов, выравнивание, вставка и удаление, отмена удаления тостом.
