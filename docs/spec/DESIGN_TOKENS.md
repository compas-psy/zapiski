# DESIGN TOKENS — КОМПАС.ЗАПИСКИ

Единственный источник цвета, типографики и метрик. **В компонентах не должно быть ни одного hex-значения** — только `var(--*)`. Смена темы и акцента — рантайм, без перезагрузки.

---

## 1. Архитектура темизации

Два независимых измерения:

1. **Тема (surface):** `paper` (Бумага, светлая, по умолчанию) · `graphite` (Графит, тёмная) · `ink` (Чернила, OLED).
2. **Акцент:** `garnet` (Гранат, по умолчанию) · `pine` (Хвоя, семейный КОМПАС) · `gold` (Золото) · `blueberry` (Черника) · `heather` (Вереск) · `slate` (Грифель).

Комбинируются свободно: 3 × 6 = 18 валидных сочетаний, каждое обязано проходить контраст AA.

Реализация: `data-theme` и `data-accent` на корне; переменные переопределяются каскадом. Тема по умолчанию — `system` (следует за ОС): светлая → `paper`, тёмная → `graphite`; `ink` выбирается вручную.

```css
:root[data-theme="paper"] {
  --bg:            #FBFAF7;  /* фон приложения */
  --surface:       #F3F1EA;  /* панели, поля, чипы */
  --surface-alt:   #F7F5EF;  /* сайдбар, тулбар */
  --line:          #EAE6DB;  /* разделители, границы */
  --line-soft:     #F0EDE4;  /* строки списка */
  --text:          #38342E;  /* основной текст */
  --text-secondary:#8A8375;  /* сниппеты, подписи */
  --text-tertiary: #B6AFA2;  /* даты, счётчики, плейсхолдеры */
  --text-disabled: #C8C1B4;  /* пустой чекбокс, неактивное */
  --scrim:         rgba(30,26,22,.32);
}
:root[data-theme="graphite"] {
  --bg:            #232120;
  --surface:       #2C2A28;
  --surface-alt:   #2C2A28;
  --line:          #393630;
  --line-soft:     #2C2A28;
  --text:          #E9E5DC;
  --text-secondary:#9B948A;
  --text-tertiary: #6E675C;
  --text-disabled: #55504A;
  --scrim:         rgba(0,0,0,.35);
}
:root[data-theme="ink"] {          /* OLED: истинный чёрный */
  --bg:            #000000;
  --surface:       #151412;
  --surface-alt:   #0D0C0B;
  --line:          #26231E;
  --line-soft:     #1A1917;
  --text:          #E9E5DC;
  --text-secondary:#8F887D;
  --text-tertiary: #635D54;
  --text-disabled: #4A453D;
  --scrim:         rgba(0,0,0,.5);
}
```

### Акценты

Каждый акцент — тройка: `--accent` (заливка/интерактив), `--accent-soft` (фон чипа/подсветки), `--accent-on-soft` (текст на soft). Значения различаются для светлых и тёмных тем.

| Акцент | Светлые темы: accent / soft / on-soft | Тёмные темы: accent / soft / on-soft |
| --- | --- | --- |
| **garnet** (по умолч.) | `#B5503C` / `#F6E7E2` / `#93412F` | `#D0765B` / `rgba(208,118,91,.18)` / `#F0B9A4` |
| **pine** (семейный) | `#2E6B4F` / `#E2EDE6` / `#256247` | `#5FA97A` / `rgba(95,169,122,.18)` / `#A8D9BB` |
| **gold** | `#B08430` / `#F5EBD8` / `#8E6A24` | `#CC9E50` / `rgba(204,158,80,.18)` / `#E8C88A` |
| **blueberry** | `#4C6B94` / `#E4EAF2` / `#3D577A` | `#7C9DC9` / `rgba(124,157,201,.18)` / `#B4CBE6` |
| **heather** | `#7C6390` / `#EFE9F3` / `#654E78` | `#A88BBD` / `rgba(168,139,189,.18)` / `#D2BFE0` |
| **slate** | `#6B675F` / `#EDEBE6` / `#54514A` | `#9B948A` / `rgba(155,148,138,.18)` / `#CBC5BB` |

### Функциональные (приглушённые, «ошибки не кричат»)

| Роль | Светлые | Тёмные |
| --- | --- | --- |
| success / синк ок | `#5C8A6E` на `#E7F0E8` | `#7FB894` на `rgba(127,184,148,.16)` |
| warning / подписка | `#B08430` на `#F5EBD8` | `#D6B26A` на `rgba(214,178,106,.16)` |
| danger / удаление | `#A85045` на `#F6E5E2` | `#D08476` на `rgba(208,132,118,.16)` |
| info / история | `#4C6B94` на `#E4EAF2` | `#7C9DC9` на `rgba(124,157,201,.16)` |

Индикатор синка: точка 6 px, success = синхронизировано, text-tertiary = оффлайн, warning = в процессе. Пульсация запрещена.

### Подсветка кода

Пастельная, в тон теме. Светлые: keyword `#8E7BA3`, string `#5C8A6E`, number `#B08430`, comment `--text-tertiary`, function `#4C6B94`. Тёмные: `#B7A2CC`, `#7FB894`, `#D6B26A`, `--text-tertiary`, `#7C9DC9`. Фон блока — `--surface`.

## 2. Типографика

| Роль | Семейство | Размер / интерлиньяж | Вес | Трекинг |
| --- | --- | --- | --- | --- |
| H1 экрана / заголовок заметки (desktop) | Golos Text | 30 / 1.2 | 700 | −0.02em |
| H1 mobile | Golos Text | 24 / 1.25 | 700 | −0.02em |
| H2 в заметке | Golos Text | 19 / 1.35 | 600 | −0.01em |
| Текст заметки (default) | Golos Text | 16 / 1.65 | 400 | 0 |
| Текст заметки (serif-режим) | Source Serif 4 | 17 / 1.7 | 400 | 0 |
| Текст заметки (компактный) | Golos Text | 14.5 / 1.5 | 400 | 0 |
| Строка списка заметок — заголовок | Golos Text | 15 / 1.35 | 600 | 0 |
| Строка списка — сниппет (2 строки, ellipsis) | Golos Text | 13 / 1.45 | 400 | 0 |
| Кнопки, пункты меню | Golos Text | 14.5–15 | 600 | 0 |
| Секционные подписи | Golos Text | 10.5 CAPS | 700 | 0.09em |
| Даты, счётчики, код, raw | JetBrains Mono | 10.5–13 | 400 | 0 |

**Шрифты:** основной — **Golos Text** (отличная кириллица, свободная лицензия); serif-опция — **Source Serif 4**; моно — **JetBrains Mono**. Все три поставляются в сборке (self-hosted `.woff2`), без обращения к CDN в рантайме.

**Пользовательские настройки редактора:** размер (5 ступеней: 14 / 15 / 16 / 18 / 20), интерлиньяж (1.45 / 1.65 / 1.85), ширина колонки (640 / 720 / вся ширина), sans ↔ serif, компактный режим. Все — множители над базовыми токенами, а не отдельные наборы значений.

**Правило markdown-вёрстки:** заголовки различаются **размером и насыщенностью, не цветом**. Маркеры списков — акцентного цвета, деликатные. Ссылки — акцент + пунктирное подчёркивание `1px dashed`.

## 3. Метрики, форма, motion

**Spacing:** база 4 px. Шкала 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40. Внутренние отступы: строка списка 11×16, карточка 16×18, экран mobile 24, редактор desktop — колонка max 640 px, паддинг 32.

**Радиусы:** `--r-sm` 10 (чипы-поля, мелкие кнопки) · `--r-md` 12–13 (поля ввода, плитки) · `--r-lg` 14 (кнопки, карточки-опции) · `--r-xl` 16 (модальные карточки, bottom sheet — только верхние углы `16 16 0 0`) · `--r-full` 99 (чипы, теги, аватары, поисковая «пилюля»).

**Границы и тени:** тонкие разделители 1 px `--line` **вместо карточек с тенью**. Elevation только для модальных слоёв: bottom sheet `0 -12px 40px var(--scrim)`, drawer `12px 0 40px`, FAB `0 8px 24px accent@35%`, плавающая поисковая панель `0 6px 22px rgba(56,52,46,.10)` + градиент-фейд 96 px над ней.

**Иконки:** единый набор, stroke 1.75, viewBox 24, round caps/joins, `currentColor` (Lucide-класс). Размеры: 20 в шапках, 17–19 в тулбаре, 15 в списках, 13 инлайн.

**Touch-targets:** ≥44 dp всегда. FAB 52×52, радиус 18.

**Motion:** 200–300 мс, `ease-out`. Появление — fade + сдвиг снизу 8 px. Press — `scale(0.97)`. Запрещено: пульсации, bounce/overshoot, параллакс, конфетти, красные бейджи-счётчики. При `prefers-reduced-motion` — все переходы мгновенные, анимации отключены.

**Фирменная деталь (проработать отдельно):** проявление markdown-синтаксиса у курсора — символы `**`, `#`, `>` фейдятся в `--text-disabled` за 160 мс при входе курсора в узел и исчезают при выходе. Никакого сдвига layout: символы всегда занимают место, меняется только opacity.

## 4. Чек-лист темизации для разработчика

- [ ] Ни одного hex вне токен-файла (правило линтера).
- [ ] Каждая из 18 комбинаций тема × акцент проверена на контраст 4.5:1 для `--text`, `--text-secondary` и `--accent` на `--bg` и `--surface`.
- [ ] «Чернила» — истинный `#000`, проверено на OLED-устройстве.
- [ ] Смена темы и акцента не требует перезагрузки и не мигает белым.
- [ ] Тема по умолчанию следует за системной; выбор пользователя перекрывает и переживает перезапуск.
- [ ] Подсветка кода переключается вместе с темой.
- [ ] `prefers-reduced-motion` и масштаб шрифта ОС до 200% не ломают ни один экран.
