# VOICE — голос → Markdown

Спецификация ключевой фичи развития (P1). Дополняет `README.md` §5, `SCREENS.md` и `BEHAVIOR.md`. Макеты — ход 3 (`3a`–`3e`) в `ЗАПИСКИ Дизайн.dc.html`.

---

## 1. Зачем это и почему сейчас

Голосовые заметки с транскрибацией — задокументированная боль пользователей Bear (их нет вовсе) и слабое место Obsidian (только через плагины). До 2026 года честно бесплатно это было не сделать: качественный русский ASR стоил денег за минуту.

**Что изменилось.** Сбер выложил в открытый доступ под лицензией MIT семейство **GigaAM Multilingual** (ASR: русский, английский, казахский, киргизский, узбекский) и облегчённую **GigaChat3.1-Audio-10B**. Компактная версия GigaAM работает на обычном процессоре, флагманская даёт более высокое качество; заявленное качество — заметно выше ближайших открытых аналогов на русском.

**Следствие для продукта:** расшифровка может выполняться **локально и бесплатно**, а значит впервые совпадает с нашим принципом «приватность по умолчанию». Мы не пересылаем запись на чужие серверы и не берём за это денег.

**Позиционирование:** «Наговорил — получил заметку». Не «AI-фича», а естественное продолжение принципа «ноль трения»: мысль ловится голосом там, где неудобно печатать (в машине, на прогулке, сразу после сессии).

## 2. Конвейер

```
запись .opus ──▶ [1] ASR: GigaAM ──▶ сырой текст + таймкоды ──▶ [2] LLM: Qwen (Ollama) ──▶ Markdown
                                              │                                    │
                                    сохраняется как оригинал           абзацы хранят ссылку на таймкод
```

**Шаг 1 — расшифровка.** GigaAM. Выход: текст, разбитый на сегменты, каждый с `start`/`end` в миллисекундах. Сегменты — единица привязки к аудио.

**Шаг 2 — оформление.** Локальная LLM через Ollama (рекомендация: Qwen 7–8B в квантовании Q4 — разумный баланс для домашнего ПК; на слабых машинах — 3B). Задача модели узкая и проверяемая: расставить пунктуацию, убрать слова-паразиты и повторы, разбить на абзацы, выделить заголовок, списки и чекбоксы по выбранному стилю. **Модель не имеет права придумывать факты, добавлять выводы или менять формулировки говорящего** — это записано в системном промпте и проверяется приёмочным тестом.

Каждый выходной абзац получает `source: [ids сегментов]` → отсюда таймкод. Если модель слила несколько сегментов в абзац, берётся `start` первого.

### Три места обработки (выбор пользователя)

| Режим | Где считает | Цена | Когда предлагать |
| --- | --- | --- | --- |
| **На этом устройстве** | GigaAM compact + Qwen 3B на телефоне/ПК | Бесплатно | По умолчанию для записей <5 мин; единственный полностью оффлайновый |
| **На моём компьютере** | Телефон отдаёт запись десктопной сборке ЗАПИСОК по локальной сети; там GigaAM flagship + Qwen 7B через Ollama | Бесплатно | Как только обнаружен свой ПК в сети — предлагать один раз, ненавязчиво |
| **Облако КОМПАС** | Наши серверы в РФ | Подписка | Для тех, кто не хочет настраивать; запись удаляется сразу после обработки |

**Связка «телефон ↔ мой компьютер»** — отдельная ценность, которой нет у конкурентов: домашний ПК работает как приватный сервер обработки. Сопряжение — по QR-коду или 6-значному коду в локальной сети, транспорт — mTLS, никакого промежуточного сервера.

**Деградация.** ПК не в сети → предложить обработать на устройстве («будет дольше») либо отложить в очередь до появления ПК. Запись **никогда не теряется**: она сохраняется в заметку сразу, оформление — асинхронная операция поверх.

## 3. Стили оформления

Пять пресетов, ровно столько (больше — паралич выбора). Стиль по умолчанию настраивается; в момент оформления его можно сменить и **переоформить сколько угодно раз из оригинала** — не из уже оформленного текста.

| Стиль | Что делает | Типичный случай |
| --- | --- | --- |
| **Как есть** | Только пунктуация и абзацы. Ни одно слово не удалено | Юридически чувствительные записи, цитаты |
| **Заметка** *(умолч.)* | Чистый связный текст, заголовок, абзацы | Мысли на ходу, дневник рабочего дня |
| **Конспект** | H2-секции, тезисы списком, ключевые формулировки цитатой | Супервизия, лекция, вебинар, книга |
| **Задачи** | Чекбоксы, императивные формулировки, срок если назван | Планёрка, «надо не забыть» |
| **Дневник** | Первое лицо, абзацы, без списков и заголовков | Личные записи |

Промпт стиля хранится в приложении, редактированию пользователем не подлежит (P2 — «свой стиль» для ЗАПИСКИ+).

## 4. Связь голоса и Markdown — фирменная деталь

**Абзац помнит, как он был сказан.** У каждого абзаца, полученного из записи, слева — время моно 10.5 `--text-tertiary` (на mobile появляется при удержании, на desktop — постоянно в режиме сверки).

| Действие | Результат |
| --- | --- |
| Тап по таймкоду | Воспроизвести с этого места, абзац подсвечивается `--accent-soft` |
| Long-press абзаца (mobile) | ТП + мини-плеер снизу, воспроизведение с начала абзаца |
| Alt+клик по абзацу (desktop) | То же |
| Во время воспроизведения | Текущий абзац подсвечен; скролл следует за ним, если пользователь не скроллил сам последние 5 с |

**Правка не рвёт связь:** редактирование текста абзаца сохраняет привязку; разбиение абзаца — оба наследуют таймкод; полностью переписанный абзац теряет метку молча (без предупреждений).

**Режим сверки** (`3e`, desktop): две колонки — слева оригинал расшифровки с таймкодами, справа оформленная заметка. Синхронная подсветка: клик по абзацу справа подсвечивает и прокручивает источник слева, и наоборот. Кнопка «Принять и закрыть сверку» переводит заметку в обычный режим; оригинал остаётся в истории версий.

## 5. Приватность и доверие

1. **Оригинал расшифровки хранится всегда** и доступен в один тап («Оригинал» в шапке заметки). Он же — версия в истории. Пользователь всегда может убедиться, что модель ничего не выдумала.
2. **Ни байта в сеть без явного выбора.** Режимы «на устройстве» и «на моём компьютере» не делают ни одного внешнего запроса. В статусе обработки прямым текстом написано, где она идёт.
3. **Аудио** по умолчанию хранится в `attachments/` рядом с заметкой и удаляется через 30 дней (настраивается: 7 / 30 / 365 дней / никогда / не хранить вовсе).
4. **Зашифрованные заметки:** аудио шифруется вместе с заметкой; обработка возможна только в режиме «на устройстве» или «на моём компьютере» — облачный режим для них **недоступен и скрыт**, а не «выключен».
5. **Модели скачиваются по запросу** (GigaAM compact ≈ несколько сотен МБ), а не зашиты в APK: размер установщика из `README` §6 не нарушается. Экран загрузки честно называет объём и позволяет отменить.

## 6. Поведение (дополнение к `BEHAVIOR.md`)

### 6.1. Запись (`3a`)

Старт: кнопка микрофона в тулбаре редактора, виджет «Быстрая надиктовка», глобальный хоткей на десктопе. Запись стартует **мгновенно**, без промежуточных экранов и без запроса стиля.

- Экран записи: таймер моно 34 px, живая вейвформа (последние ~18 столбцов, обновление 20 fps, активные — акцент), под ней — потоковая расшифровка `--text-secondary`, последние 2–3 строки; неподтверждённый хвост — `--text-disabled`.
- Кнопки: пауза · стоп (акцентный круг 68) · отмена. Отмена — единственная деструктивная, спрашивает подтверждение, если записано >10 с.
- **Прерывание звонком/системой:** запись автоматически ставится на паузу и сохраняется; после звонка — предложение «Продолжить запись» 60 секунд, дальше сохраняется как есть.
- Экран можно свернуть: запись продолжается в фоне, в шапке списка — чип «Идёт запись · 02:14», тап возвращает.
- Лимит одной записи: 3 часа (ограничение сверху, чтобы не съесть память); за 5 минут до лимита — деликатное предупреждение в чипе.

### 6.2. Оформление (`3b`)

- Bottom sheet с двумя строками статуса: «Расшифровано» (✓, длительность и число слов) и «Оформляем в заметку» (прогресс-линия + где именно идёт обработка).
- Стиль выбирается **во время** обработки — смена не перезапускает расшифровку, только шаг 2.
- Плашка приватности с иконкой замка — обязательна.
- Кнопка «Отменить оформление» оставляет сырую расшифровку как заметку (ничего не теряется).
- Долгие записи: sheet сворачивается, обработка идёт в фоне, по завершении — тост «Заметка оформлена · Открыть». Приложение можно закрыть — очередь переживает перезапуск.
- **Ошибки:** модель не отвечает → «Не удалось оформить. Расшифровка сохранена — попробовать снова?»; мало места → расшифровка сохраняется, аудио не сохраняется, с честным сообщением.

### 6.3. Результат (`3c`)

Шапка заметки получает три чипа: «Оформлено · <Стиль>» · «Оригинал» · «Переоформить». Чипы исчезают, когда пользователь принял результат (кнопка в меню «⋯» → «Принять») либо через 7 дней. «Оригинал» — переключение вида, не отдельный экран; переключение мгновенное, без анимации.

Undo: «Переоформить» — ОО, старый вариант уходит в историю версий.

## 7. Влияние на тарифы

| | Бесплатно | ЗАПИСКИ+ |
| --- | --- | --- |
| Запись голоса, хранение аудио | ✓ без ограничений | ✓ |
| Расшифровка на устройстве | ✓ без ограничений | ✓ |
| Обработка на своём ПК | ✓ без ограничений | ✓ |
| Обработка в облаке КОМПАС | — | ✓ 10 часов/мес |
| Свои стили оформления (P2) | — | ✓ |

Это сильнее исходной модели из концепции («10 мин/мес транскрибации бесплатно»): бесплатный тариф становится по-настоящему честным, а платить предлагается **за удобство, а не за снятие ограничения**. Позиция в маркетинге: «Транскрибация без лимитов и без интернета — потому что считает ваше устройство, а не наш сервер».

## 9. Открытые вопросы

- Лицензионная чистота выбранных весов **под коммерческое использование**: у семейства GigaAM исторически часть моделей публиковалась под некоммерческой лицензией, а свежий релиз — под MIT. **Перед V1 обязательно зафиксировать конкретные веса, версию и текст лицензии в `docs/adr/` и приложить к юридической проверке.**
- Выбор модели оформления: Qwen 7B vs 3B — по итогам замеров на домашнем железе; нужен fallback для слабых машин.
- Нужна ли диаризация («кто говорит») для супервизий и интервью — сильно расширяет ценность, но и скоуп. Кандидат на P2.
- GigaChat Audio умеет работать с аудио напрямую и распознаёт эмоции — интересно для будущего, но **эмоции в наш продукт не берём**: анализ чувств пользователя противоречит тону и обещанию приватности.
- Определение языка записи автоматически или вручную (GigaAM Multilingual поддерживает 5 языков).
