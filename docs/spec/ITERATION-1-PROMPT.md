# Промпт для Claude Code — итерация 1

```
Прочитай design_handoff_zapiski/ITERATION-1.md целиком. Это доработки после
первой сборки; он важнее BEHAVIOR.md и DS-ALIGNMENT.md там, где расходится.

Первая сборка удалась — ничего не переписывай целиком. Девять задач, порядок
работ в конце документа, начинай с локализации.

Каждую задачу закрывай отдельным коммитом с номером раздела в сообщении
(например «feat(editor): 1 отдельное поле заголовка»). После каждой задачи
проходи её пункт из чек-листа приёмки.

Жёсткие правила, которые уже действуют и не отменяются:
- ни одного hex вне токен-слоя;
- --app-disabled никогда не текст;
- терракота только как знак сервиса;
- русский, «вы», без восклицательных знаков;
- строки только через i18n-каталоги.

Отдельно: панель форматирования (§4) рисуем в наших токенах. Присланный
референс задаёт паттерн — плавающие пилюли с выпадающими меню, — но не
внешний вид: иконки, радиусы, цвета и тени берём из COMPONENTS.md.

Если чего-то не хватает в спецификации — остановись и спроси, приложив
скриншот. Не изобретай.
```
