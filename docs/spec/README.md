## 1. Продукт в одном абзаце

**ЗАПИСКИ** — спокойное, быстрое приложение для заметок в Markdown. Локальные `.md`-файлы, опциональное шифрование, синхронизация: бесплатно — через своё хранилище (WebDAV, Яндекс.Диск, локальная папка), по подписке — через Облако Записок. Ориентиры: Bear (лаконичность) и Obsidian (владение данными). **Не** Notion: никаких баз данных, канбанов, таблиц-как-БД.

**Красные линии (никогда):** базы данных и формулы · канбан · встроенный календарь-планировщик · таск-менеджер с напоминаниями · сторонние плагины · геймификация · лента/соцсеть.

**Связь с экосистемой.** ЗАПИСКИ — самостоятельный B2C-продукт, а не суббренд (Р1, Р5). Связь с приложением практики **однонаправленная**: из практики можно открыть Записки, заметка в Записках на карточку клиента не ссылается. Чипа связи в шапке заметки **нет** — он убран по `tz/ZAPISKI_TZ_1_Design.md` §1.2. Заметки о клиентах живут в приложении практики, где шифрование и серверы в РФ обязательны архитектурно (`tz/ZAPISKI_TZ_0_Master.md` §7).

## 2. Архитектурные принципы и стек

### 2.1. Принципы (немодифицируемые)

1. **File over app.** Источник истины — папка с `.md`-файлами и вложениями на устройстве. Внутренний индекс (SQLite) — производная, всегда восстановим из файлов.
2. **Local-first.** Всё работает полностью оффлайн. Синхронизация — надстройка, а не условие работы.
3. **Один редактор на всех платформах.** Главный урок рынка: Obsidian провалил Android из-за расхождения платформ. Редактор — единая кодовая база.
4. **Конфликты не теряют данные — никогда.** Автослияние + версия проигравшей стороны в истории.
5. **Zero-knowledge шифрование.** Сервер технически не может расшифровать пользовательские данные.
6. **Ноль трения.** От иконки до курсора в новой заметке — меньше 2 секунд. Всегда.

### 2.2. Стек (рекомендация; отклонения — только с обоснованием в ADR)

Монорепо TypeScript + Rust, оболочка Tauri 2:

| Слой | Технология | Обоснование |
| --- | --- | --- |
| Ядро (домен, синк, крипто, индекс) | **Rust** (crate `zapiski-core`) | Один код для FS, CRDT, шифрования на Win/Android/iOS |
| UI | **TypeScript + React** | Один UI-код на все платформы |
| Редактор | **CodeMirror 6** + кастомные расширения live-preview | Зрелость, перф, контроль над рендерингом, хорошая поддержка IME/кириллицы |
| Desktop (Windows → macOS/Linux) | **Tauri 2** | Лёгкий, Rust-ядро нативно |
| Android (mobile/tablet) → iOS | **Tauri 2 Mobile** | Единая кодовая база. **Риск-зона**, см. ниже |
| Web (PWA) | Тот же React + `zapiski-core` в **WASM**; OPFS/File System Access API | Максимум переиспользования |
| Индекс/поиск | SQLite + FTS5 (`rusqlite`); web — SQLite WASM | Мгновенный полнотекст оффлайн |
| CRDT | **Automerge** (Rust) или Yrs | Автослияние без конфликтов |
| Облако Записок | Rust (axum) или Go; PostgreSQL + S3-совместимое хранилище **в РФ** (152-ФЗ) | Blob-синк зашифрованных чанков |

**Риск-зона №1.** До старта разработки — 2-недельный спайк качества WebView-редактора на Android: IME, Gboard / Яндекс.Клавиатура / SwiftKey, автозамена, свайп-ввод, скролл при появлении клавиатуры, кириллица. Go/no-go по стеку. **Fallback:** React Native с тем же Rust-ядром через UniFFI, редактор в RN WebView.

## 3. Модель данных

### 3.1. Файловая структура vault'а

```
Мои заметки/
  Заметка о встрече.md
  Проекты/
    Идея продукта.md
  attachments/
    2026-08-08_1a2b3c.png
  .zapiski/              # служебное, скрыто
    index.sqlite         # поисковый индекс (восстановим)
    crdt/                # CRDT-логи по заметкам
    versions/            # локальная история версий
    trash/               # корзина, 30 дней
    config.json
```

### 3.2. Формат заметки

- Чистый Markdown (CommonMark + GFM: таблицы, чекбоксы, зачёркивание) + расширения: `[[wiki-links]]`, `==highlight==`, сноски, `#вложенные/теги` инлайн.
- YAML frontmatter — **опционален**: приложение его сохраняет, но не требует (совместимость с Obsidian-vault'ами). Служебные метаданные (created/updated/pinned/id) — во frontmatter при наличии, иначе в индексе.
- Имя файла = заголовок (первая H1/строка); безопасная транслитерация запрещённых символов; переименование обновляет wiki-ссылки.
- **Вложения:** всегда относительные пути `attachments/…`, единая конвенция на всех платформах (фикс главной боли Obsidian). Вставка изображения = копирование в `attachments/` + `![](attachments/…)`.

### 3.3. Шифрование

- Формат `*.md.enc`: контейнер (magic, версия, salt, nonce) + AES-256-GCM полезная нагрузка (md + манифест вложений). KDF: **Argon2id**.
- Иерархия ключей: master key из пароля → per-note keys. Биометрия разблокирует master key из платформенного хранилища (Android Keystore / Windows Hello / WebAuthn-PRF на web).
- Зашифрованные заметки **не попадают в индекс** (ни заголовок, ни тело); в списке — плейсхолдер. Расшифровка только в памяти; открытый текст на диск не пишется никогда.
- **Автозамок:** расшифрованная заметка закрывается через 10 минут бездействия (значение настраивается: 1 / 5 / 10 / 30 мин / до выхода). При сворачивании приложения — скрывать содержимое в превью задач ОС (FLAG_SECURE на Android).
- Восстановление пароля невозможно — и это сказано пользователю прямым текстом на экране установки (см. `SCREENS.md` → «Шифрование: установка»).

## 4. Синхронизация

### 4.1. Бэкенды (интерфейс `SyncBackend` в ядре)

1. **LocalFolder** — просто папка (в т.ч. синкаемая сторонним клиентом: приложение Яндекс.Диска, Syncthing).
2. **WebDAV** — универсальный, включая Яндекс.Диск по WebDAV; для Я.Диска дополнительно нативный REST OAuth-коннектор для скорости.
3. **KompasCloud** — собственный протокол: push/pull CRDT-логов и blob-чанков, delta-синк, websocket для мгновенности.

### 4.2. Алгоритм

- Текст заметки — CRDT-документ; `.md` на диске — его материализация. Для WebDAV/локали храним и `.md`, и компактный CRDT-лог в `.zapiski/crdt`.
- WebDAV-цикл: ETag/`getlastmodified` → three-way merge через CRDT-лог. Если у контрагента лога нет (правили чужим редактором) — line-based three-way merge (diff3). При неразрешимости обе версии сохраняются, «чужая» уходит в `versions/`, пользователю — тихое уведомление «объединили, история тут».
- Гибридный режим: **облачная версия главная**; локальные расхождения вливаются в неё, снапшот локальной — в историю.
- История версий: локально последние 50 снапшотов на заметку; KompasCloud — 30 дней (пробный) / 365 (подписка).

### 4.3. Устойчивость

- Прерывание синка на любом байте не портит файл: атомарная запись (tmp + rename).
- Часы устройства не влияют на корректность (логические часы CRDT).
- **Тест-сьют «злого синка»:** параллельная правка одной заметки на 3 устройствах оффлайн → все сходятся к одному состоянию без потерь. Обязателен к зелёному статусу в DoD.

## 5. Функциональные требования MVP

### 5.1. Редактор (приоритет №1)

- **Live-preview:** разметка скрыта, проявляется у курсора (декорации CodeMirror; эталон поведения — Obsidian Live Preview / Bear). Переключение в raw-режим (Ctrl+E).
- **Элементы:** H1–H6, bold/italic/strike/highlight, списки (маркер/нумерация/чекбоксы, drag-перестановка на desktop), цитаты, код-блоки с подсветкой (~20 языков), таблицы GFM с Tab-навигацией, изображения инлайн, ссылки, wiki-ссылки с автодополнением, сноски, разделители.
- **Заголовок** = первая строка (H1 автоматически, отдельного поля нет).
- **Теги** — инлайн `#тег` с автодополнением, дублируются чипами в шапке.
- **Панель «Инфо»:** даты, статистика, backlinks, вложения, экспорт, шифрование.
- **Режим фокуса:** скрыть всё, кроме текста; опционально — затемнить всё, кроме текущего абзаца (см. макет).
- Тулбар над клавиатурой (mobile, одна строка: H, B, I, список, чекбокс, фото, микрофон, ещё), палитра команд Ctrl+K (desktop), полные хоткеи (Ctrl+N, Ctrl+P/K, Ctrl+E).
- Undo/redo глубиной сессии; автосохранение (debounce 500 мс + on-blur). **Слова «сохранить» в UI нет.**
- **Перф:** заметка 1 МБ — ввод без лагов (<16 мс на кейстрок); открытие заметки <150 мс.
- **QA-приоритет №1:** мобильный ввод — Gboard, Яндекс.Клавиатура, SwiftKey, автозамена, свайп-ввод, кириллица, эмодзи, диктовка ОС. Регрессионные e2e-тесты на реальных устройствах.

### 5.2. Организация и поиск

- Папки (реальные каталоги ФС), вложенные теги, закрепление, архив, корзина (30 дней, восстановление).
- FTS5-поиск: <50 мс на 10 000 заметок; операторы `tag:`, `folder:`, `before:/after:`, `has:image|file|todo`; подсветка совпадений; поиск в заметке Ctrl+F; недавние запросы.
- Backlinks: индекс wiki- и markdown-ссылок между заметками, панель в редакторе. **Графа связей нет** (сознательно).
- Свайпы в списке (mobile): вправо — закрепить, влево — в архив.

### 5.3. Импорт/экспорт

- **Импорт:** папка `.md` (Obsidian-vault как есть, с attachments), Bear (`.bear2bk`/textbundle), Notion (zip: md+csv → md, csv как markdown-таблицы), Evernote (`.enex`).
- **Экспорт:** md (zip), PDF, HTML, DOCX — всё бесплатно, без paywall (прямой ответ на боль Bear).

### 5.4. Платформенные фичи

- **Android:** share-target (текст/ссылка/изображение → новая или существующая заметка), виджеты (быстрая заметка 1×1, последние 2×2, закреплённая 2×2), Quick Settings tile, деликатная хэптика (чекбоксы, завершение действий).
- **Windows:** глобальный хоткей быстрой заметки, автозапуск в трей (опция), ассоциация `.md`.
- **Web/PWA:** установка, offline, File System Access API для локального vault (Chromium), OPFS иначе.

### 5.5. Аккаунт и монетизация

> **⚠ Изменение против TZ v1.0.** SMS-авторизация исключена из скоупа: платные SMS-шлюзы недоступны на текущем этапе. Ни один флоу не должен зависеть от отправки SMS.

- **Локальный режим — без аккаунта вообще.** Онбординг завершается курсором в первой заметке, регистрации нет.
- **Аккаунт нужен только для Облака Записок** (и веб-доступа/публикации). Способы входа:
  1. **Яндекс ID (OAuth)** — основной путь, бесплатен для нас;
  2. **Magic-link на email** — письмо со ссылкой, вход в один тап. Токен одноразовый, TTL 15 мин, привязан к устройству инициации;
  3. *(опционально, P1)* Telegram Login Widget — бесплатен, уместен для нашей аудитории.
- **Паролей нет.** Нет экрана «придумайте пароль» и нет «забыли пароль» — только для шифрования заметок пароль существует (это другой контур, локальный).
- SSO с приложением практики — общий аккаунт, но **вход в ЗАПИСКИ никогда не требует практики**.
- Подписка: ЮKassa (веб/десктоп) + Google Play Billing (Android); серверная валидация, grace period, восстановление покупок.
- Тариф: free — всё, кроме KompasCloud и публикации по ссылке. **При истечении подписки заметки остаются доступны локально** — блокировки данных нет никогда. Цена: 199 ₽/мес, 149 ₽/мес при годовой оплате.

## 6. Нефункциональные требования

| Категория | Требование |
| --- | --- |
| Производительность | Холодный старт: Android <1.5 c, Windows <2 c. Список 10 000 заметок — плавный скролл (виртуализация) |
| Размер | Android APK <30 МБ, Windows installer <25 МБ |

## 8. Definition of Done (MVP)

**Инженерия**
- Сьют «злого синка» зелёный на матрице Android × Windows × Web × (WebDAV, Я.Диск, локально).
- Ввод на Android-клавиатурах без багов класса «символы-призраки» (регрессия по списку известных болей Obsidian).
- Импорт реального Obsidian-vault на 1000+ заметок с вложениями — без потерь, ссылки работают.
- Шифрование: независимая проверка (тест-векторы, отсутствие plaintext на диске, memory-safety обзор).
- Перф-бюджеты §6 подтверждены на среднебюджетном Android (класс Redmi/Galaxy A).
- Ни одного SMS-зависимого пути в кодовой базе.

**Дизайн**
- Любой экран узнаваем как ЗАПИСКИ без логотипа: «Бумага» + «Гранат» (`tz/ZAPISKI_TZ_1_Design.md` §1).
- Ни одного экрана, где текст заметки занимает <80% площади в режиме чтения/письма.
- Тёмные темы проверены на OLED: «Чернила» — истинный чёрный, без грязных серых заливок.
- Все три темы и все шесть акцентов проходят контраст 4.5:1 на текстовых парах.
- Ни одного хардкоженного цвета вне токен-файла (проверяется линтером).

**Поведение**
- Все 10 приёмочных критериев `BEHAVIOR.md` §13 пройдены вручную на реальном устройстве.
- Каждая ячейка матрицы «экран × состояние» (`BEHAVIOR.md` §12) воспроизводима в отладочном меню.
- Все хоткеи и жесты из `BEHAVIOR.md` §7 работают и перечислены в палитре команд.
- Тексты всех ошибок соответствуют реестру `BEHAVIOR.md` §11 дословно.
