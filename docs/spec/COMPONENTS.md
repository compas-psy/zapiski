# COMPONENTS — библиотека компонентов

Все значения — токены из `DESIGN_TOKENS.md`. Макеты: `4a` (Бумага) и `4b` (Графит) в `ЗАПИСКИ Дизайн.dc.html` — те же компоненты в обеих темах, спроектированные, а не конвертированные.

Общее правило: **высота интерактивного элемента ≥44 px**, состояния — hover / press / focus / disabled у каждого. Press везде `scale(0.97)`, 120 мс. Focus — кольцо 3 px `--accent` при 35–45% альфы, видимо только при навигации с клавиатуры (`:focus-visible`).

---

## 1. Кнопки

| Вариант | Фон | Текст | Применение |
| --- | --- | --- | --- |
| **Основная** | `--accent` | светлые темы — белый; тёмные — `#241511` (тёмный на светлом акценте) | Одно главное действие на экране |
| **Вторичная** | `--surface` | `--text` | Рядом с основной |
| **Контурная** | прозрачный + 1 px `--line` | `--text` | На карточках и поверх фона |
| **Текстовая** | нет | `--accent` | Третьестепенное, ссылки-действия |
| **Деструктивная** | danger-soft | danger-fg | Удаление, снятие шифрования |
| **Иконочная** | `--surface` | `--text-secondary` | 44×44, радиус 14 |

Метрики: радиус 14, высота 44 (компактная 36 в плотных панелях), паддинг 11×22, вес 600, размер 14–15.

Состояния: hover — на один шаг темнее для заливок (`#B5503C` → `#9C432F`), `--surface` → `--surface-alt` для остальных; **никогда не уменьшать непрозрачность для основной кнопки**. Disabled — `opacity .45` + `not-allowed`. Загрузка — кольцо 14 px внутри кнопки слева от текста, надпись меняется на процессную («Отправляем»), ширина не прыгает.

---

## 2. Поля ввода

Радиус 13, паддинг 12×15, размер 14, фон белый (светлые темы) / `--surface` (тёмные), рамка 1 px `--line`.

- **Фокус:** рамка 1.5 px `--accent` + кольцо 3 px акцента 18–22%.
- **Ошибка:** рамка 1.5 px danger + подпись 12 px danger под полем, отступ 6. Ошибка показывается **после blur**, не во время набора.
- **Disabled:** фон `--surface`, текст `--text-tertiary`, `opacity .7`.
- **Поиск:** радиус full, фон `--surface`, иконка лупы 15 слева, отступ 9.
- **Код/пароль:** ячейки 38×48, радиус 11; активная — рамка 1.5 акцент + курсор 2 px.

Плейсхолдер — `--text-tertiary`, никогда не заменяет подпись поля в формах длиннее двух полей.

## 3. Чипы, теги, бейджи

| Тип | Стиль |
| --- | --- |
| **Тег** | `--accent-on-soft` на `--accent-soft`, радиус full, 12 px, паддинг 4×11 |
| **Фильтр (неактивный)** | 1 px `--line`, текст `--text-secondary` |
| **Фильтр (активный)** | `--accent-soft` + рамка акцента 35–40% |
| **Фильтр со сбросом** | + крестик 10 px справа, зона нажатия 24×24 |
| **Бейдж статуса** | soft-фон + насыщенный текст: success «бесплатно», warning «подписка», danger «ошибка», info «история». 11 px, вес 600 |

Чипы никогда не переносятся внутри себя: `white-space: nowrap`; ряд чипов при нехватке места — горизонтальный скролл без полосы, не перенос на две строки.

## 4. Переключатели

- **Тумблер:** 40×24, радиус full, бегунок 18. Включён — `--accent`; выключен — `--line` потемнее. Переход 200 мс.
- **Чекбокс:** 18×18, радиус 6. Выключен — 1.5 px `--text-disabled`; включён — заливка `--accent` + галочка. Анимация: заливка 200 мс, галочка `stroke-dashoffset` 160 мс.
- **Радио:** 18×18, круг; выбранный — кольцо 5 px акцента.
- **Сегментированный контрол:** контейнер `--surface` радиус 10, паддинг 3; активный сегмент — белый (светлые) / `--line` (тёмные), радиус 8, тень `0 1px 2px`. Переход бегунка 200 мс.

## 5. Строки списка

Высота: обычная 74, компактная 58. Паддинг 11×16. Разделитель — 1 px `--line-soft`, **не карточки**.

Состояния: hover — фон `--surface-alt`; выбранная (desktop) — фон `--accent-soft`, вторичный текст `--accent-on-soft`, **без рамки**; свайп — подложка акцентом (закрепить) или `--surface` (архив), иконка + подпись 12.5/600, строка «уезжает» поверх подложки с радиусом 12 слева.

Содержимое: заголовок 15/600 в одну строку, сниппет 13/1.45 `--text-secondary` максимум 2 строки, метастрока моно 10.5 `--text-tertiary`. Пиктограммы 13 px в строке заголовка.

## 6. Оверлеи

- **Bottom sheet (mobile):** радиус `16 16 0 0`, «ручка» 36×4 `--line`, паддинг 24 по бокам, тень `0 -12px 40px var(--scrim)`. Появление — снизу 250 мс ease-out, скрим параллельно. Закрытие — свайп вниз, тап по скриму, Esc.
- **Модалка (desktop):** ширина 480–560, радиус 16, тень `0 24px 60px`, центр по горизонтали, отступ сверху 78. Появление — fade + 8 px снизу, 200 мс.
- **Drawer:** ширина 302 (mobile) / 224 (desktop), радиус `0 22 22 0`, тень `12px 0 40px`.
- **Тост:** фон `--text` (инверсный), текст `--surface`, радиус 14, паддинг 12×16, действие — акцентом посветлее. Живёт 6 с, снизу с отступом 16, шириной по контенту, максимум ширины экрана −32. Один тост одновременно.
- **Тултип (desktop):** фон `--text`, текст 12, радиус 8, задержка появления 500 мс.

Все оверлеи закрываются по Esc и возвращают фокус на вызвавший элемент.

## 7. Обратная связь

- **Плашка-пояснение:** фон `--surface`, радиус 12, иконка 15 слева, текст 12.5/1.5 `--text-secondary`. Для приватных сообщений — иконка замка.
- **Скелетон:** плашки радиуса 5–6; заголовок 12–13 px высотой цветом на шаг темнее фона, строки 9–10 px ещё светлее. Без анимации мерцания в reduce-motion; обычно — мягкий сдвиг блика 1.4 с.
- **Прогресс:** линия 3 px, радиус 2, фон `--line`, заполнение `--accent`. Неопределённый прогресс — кольцо 14–22 px, толщина 2, только там, где неизвестен объём.
- **Пустое состояние:** круг 64 `--surface` с иконкой 26 акцентом, заголовок 16/600, пояснение 13/1.5 `--text-secondary`, ровно одна кнопка.

## 8. Специальные компоненты продукта

- **Тулбар редактора:** высота 44, фон `--surface-alt`, верхняя граница 1 px, элементы 34×34 равномерно (`space-between`), иконки 19.
- **Мини-плеер (голос):** карточка `--surface-alt`, рамка 1 px, радиус 14, кнопка 34 круглая акцентом, прогресс 3 px, тайминги моно 10, скорость справа текстом.
- **Строка с таймкодом:** время моно 10.5 `--text-tertiary` слева фиксированной колонкой, gap 10–12; активная строка — фон `--accent-soft` радиус 10, время `--accent`.
- **Вейвформа записи:** столбцы шириной 3, gap 3, радиус 2, высота от 8% до 100%; последние ~18 значений; активные — акцент, затухающие — `--line`.
- **Diff:** добавления — фон success-soft, удаления — фон danger-soft + `line-through` цветом danger-fg. Радиус подсветки 3 (инлайн) или 8–10 (блок).
- **Дерево (папки/теги):** отступ вложенности 14 px на уровень (иконка + название на 34 от края, вложенные — от 48), шеврон 13 поворачивается 200 мс.
