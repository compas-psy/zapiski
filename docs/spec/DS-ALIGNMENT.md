# Приведение к дизайн-системе СИМПАС

Дата: 2026-08-09 · Основание: `guidelines/zapiski-handoff.md` дизайн-системы СИМПАС.

**Этот документ имеет приоритет над `DESIGN_TOKENS.md` и `COMPONENTS.md` во всём, что касается палитры, шрифта, радиусов и состава компонентов.** Приоритет документов теперь: `DS-ALIGNMENT.md` > `BEHAVIOR.md` > `SCREENS.md` > `DESIGN_TOKENS.md` > `README.md`.

Поведение, флоу, тексты ошибок, спецификация голоса — **не меняются**. Меняется только оболочка.

## 1. Что было неправильно

Базовая тема ЗАПИСОК была построена на терракоте (`#B5503C`, «Гранат») как на интерфейсном акценте: кнопки, теги, чекбоксы, подсветка. По гайду СИМПАСА терракота `#C8604A` — **цвет идентичности, а не интерфейса**: иконка, сплэш, стор, брендовые места. Интерфейс всех девяти сервисов живёт на общей теме.

Продукт в текущем виде вывалился бы из семьи и спорил с остальными сервисами. Исправляется заменой значений токенов — структура тем, компоненты и вся логика остаются.

**Побочный выигрыш:** палитра СИМПАСА контрастно чистая. Форест `#1D4735` на кремовом даёт 9.82:1, `--ink-500` `#5F6C64` — 5.16:1. Большая часть долга из `CONTRAST-DECISION.md` закрывается сама; из него остаётся в силе только правило про золото и разведение статусных цветов (§4 ниже).

## 2. Светлая тема — теперь базовая и единственная «дневная»

Тема `paper` переименовывается в `simpas` и берёт значения дизайн-системы. Подключается `styles.css` СИМПАСА целиком — он импортирует токены; наши переменные становятся **алиасами поверх** его, а не независимой палитрой.

**Пакет `@simpas/design-system` приватный и в npm недоступен.** До тех пор значения системы берутся из вендорного снимка в пакете передачи: `ds/simpas.css` (входная точка) + `ds/vendor/` (побайтовые копии `styles.css`, `tokens/*.css`) + `ds/services.css`. Это снимок, а не форк: править файлы в `vendor/` нельзя, а когда пакет станет доступен — содержимое `ds/simpas.css` заменяется одной строкой `@import "@simpas/design-system/styles.css";`, и `vendor/` удаляется. Имена переменных при этом не меняются, поэтому код переезд не заметит.

Значения из §2–§5 ниже дублируют снимок только в человекочитаемом виде — **источник истины при расхождении именно снимок**, а не эта таблица.

```css
/* packages/ui/src/styles/tokens.css */
@import "../../../ds/simpas.css";   /* цвет, тип, радиусы, тени — оттуда. Позже: @simpas/design-system/styles.css */

:root[data-theme="simpas"] {
  --bg:              var(--cream);        /* #F7F8F4 */
  --surface:         var(--white);        /* карточки — белые, не бежевые */
  --surface-alt:     var(--sage-50);      /* #F6FAF6 сайдбар, тулбар */
  --surface-sunken:  var(--muted);        /* #F2F4EF поля, чипы */
  --line:            var(--border);       /* #E4E9E3 */
  --line-soft:       #EEF1EC;             /* строки списка */
  --text:            var(--ink-900);      /* #142018 — 9.9:1 */
  --text-secondary:  var(--ink-500);      /* #5F6C64 — 5.16:1 */
  --text-tertiary:   #7E8A83;             /* метаданные — 3.9:1 */
  --text-disabled:   #A3ADA7;
  --text-ghost:      #C2CBC5;             /* markdown вне курсора, хвост расшифровки */
  --scrim:           rgba(20,32,24,.32);
}
```

Прежние `#FBFAF7 / #F3F1EA / #38342E / #726C60` — **удалить**, не оставлять как «альтернативную светлую».

## 3. Акценты — переопределены

Терракота **исключается из набора интерфейсных акцентов**: предлагать пользователю красить интерфейс в цвет идентичности нельзя. Набор из шести сохраняется, по умолчанию — форест.

| Пресет | `--accent` | `--accent-soft` | `--accent-on-soft` | Текст на заливке |
| --- | --- | --- | --- | --- |
| **Хвоя** *(по умолчанию)* | `#1D4735` | `#E7F0EA` | `#1D4735` | белый |
| Лес | `#3B8F5A` | `#EAF7EE` | `#256B41` | белый |
| Золото | `#8F6B26` ¹ | `#FBF3E3` | `#886522` | **тёмный `#143D2F`** |
| Сумерки | `#4A4E78` | `#ECEDF5` | `#3E4266` | белый |
| Гранит | `#6A5F63` | `#F1EEEF` | `#584E52` | белый |
| Глина | `#A47864` | `#F6EFEA` | `#7E5A4A` | белый |

¹ Фирменное золото `#CC9E50` остаётся **только заливкой** (бейдж, премиальная кнопка) и никогда не текстом: как текст на кремовом оно даёт 2.30:1. Белая подпись на золотой заливке — 2.45:1, поэтому текст на золоте **тёмный форест-ink**, 6.86:1. Это правка к самой дизайн-системе; вынести в вопросы владельцу.

## 4. Что остаётся в силе из CONTRAST-DECISION

Разведение «цвет статуса ≠ текст статуса» сохраняется, значения берутся из СИМПАСА:

```css
--success: var(--success-500); --success-soft: var(--success-soft); --success-text: #2C6B44;
--warning: var(--gold-500);   --warning-soft: var(--amber-soft);   --warning-text: #886522;
--danger:  var(--destructive);--danger-soft:  var(--red-soft);     --danger-text:  #B23B2E;
--info:    var(--blue-500);   --info-soft:    var(--blue-soft);    --info-text:    #2C5FA8;
```

Правила употребления шкалы текста (`secondary` — то, что читают; `tertiary` — метаданные; `disabled` — контролы; `ghost` — декор) не меняются.

## 5. Тёмные темы — перекрашены в форест

У СИМПАСА тёмной темы нет; наши остаются как расширение продукта, но уходят из тёплого коричневого в холодный форест, иначе ночью продукт снова покидает семью.

```css
:root[data-theme="graphite"] {          /* было #232120 — тёплый графит */
  --bg: #121A15;  --surface: #1A241E;  --surface-alt: #16201A;
  --line: #26332B; --line-soft: #1E2A23;
  --text: #EEF4EF; --text-secondary: #9FB0A6; --text-tertiary: #75847B;
  --text-disabled: #56635B; --text-ghost: #3A4841;
  --scrim: rgba(0,0,0,.45);
}
:root[data-theme="ink"] {               /* OLED */
  --bg: #000000;  --surface: #0D1310;  --surface-alt: #080C0A;
  --line: #1B241E; --line-soft: #121915;
  --text: #EEF4EF; --text-secondary: #93A399; --text-tertiary: #6C7B72;
  --text-disabled: #4E5A53; --text-ghost: #333E38;
}
```
В тёмных темах акцент осветляется до `--forest-500 #3B8F5A` (Хвоя) и `--gold-400 #D8AE67` (Золото).

## 6. Типографика

**Golos Text заменяется на Geist Sans**, моно — **Geist Mono** (даты, времена, табличные числа, raw-режим). Шкала размеров и весов из `DESIGN_TOKENS.md` §2 сохраняется без изменений — меняется только семейство.

Source Serif 4 остаётся **только как режим чтения заметки** (опция «бумажный режим»), это продуктовое расширение поверх системы, не замена UI-шрифта. В интерфейсной хромоте serif не появляется нигде.

## 7. Форма и тень

| Роль | Было | Стало (СИМПАС) |
| --- | --- | --- |
| Поля ввода, мелкие чипы | 13 | **12** |
| Кнопки | 14 | **14–16** |
| Карточки, модалки | 12–16 | **20–22** |
| Крупные панели, bottom sheet | 16 | **24** (sheet — `24 24 0 0`) |
| Аватары, теги, пилюли | full | full |

Тени — мягкие, с зелёным подтоном: `0 8px 30px rgba(20,32,24,.06)`; hover приподнимает. Резких падающих теней нет. Разделители строк списка — по-прежнему hairline `--line`, без карточек: это плотность списка, а не спор с системой.

## 8. Компоненты — не строить заново

`COMPONENTS.md` перестаёт быть источником реализации и становится **картой соответствия**. Из системы берутся: `Button`, `Badge`, `Card`, `Input`, `Separator`, `SegmentedControl`, `Icon`, `ServiceMark`.

| Наш компонент | Реализация |
| --- | --- |
| Кнопки всех вариантов | `Button` СИМПАСА |
| Бейджи статусов, чипы-теги | `Badge` |
| Карточки настроек, опций, paywall | `Card` |
| Поля, поиск, поле пароля | `Input` |
| Разделители | `Separator` |
| Переключатель «Текст / Raw», стили оформления | `SegmentedControl` |
| Иконки интерфейса | `Icon` (набор бренда); чего нет — Lucide, stroke 1.5–1.75 |
| Знак сервиса | `ServiceMark` |

Собственными остаются только те, которых в системе нет: строка списка заметок, тулбар редактора, чекбокс markdown, вейвформа, мини-плеер, строка с таймкодом, diff. Они строятся **на токенах системы**, а не на своих значениях.

## 9. Знак, имя, терракота

- Иконка — `assets/services/zapiski.svg` как есть. Контур дерева не трогать: ни обрезки, ни перерисовки, ни добавления. Дерево — 0.74 стороны (иначе squircle-маска Android подрежет), плитка 500×500, скругление 140, фон — плашка без градиентов и бликов. Тёмная плитка — **внутренняя обводка не ставится**. Проверить читаемость на 28 px.
- **Плейсхолдер иконки из `4k` закрыт** — рисовать ничего не нужно, файл есть.
- Имя продукта в интерфейсе, сторе и переключателе — **ЗАПИСКИ**, без приставки. «КОМПАС.ЗАПИСКИ» и «СИМПАС Записки» из всех пользовательских строк убрать.
- **Бренд переименован: КОМПАС → СИМПАС.** Строковые замены в коде: «Облако КОМПАС» → «Облако СИМПАС», «КОМПАС.Дневник» → «ДНЕВНИК», подпись публичной страницы — «Опубликовано из ЗАПИСОК». СИМПАС остаётся только в оферте, футере, счетах и письмах поддержки.
- Терракота `#C8604A` внутри продукта допустима ровно в четырёх местах: иконка в шапке, пустые состояния, брендовый экран онбординга, выделение приложения в переключателе сервисов. Токен — `--svc-zapiski-bg`; **в интерфейсных токенах её нет и быть не должно**.

## 10. Следствие для плотности — не добирать активность

Гайд фиксирует расхождение: имя ЗАПИСКИ фонетически тише, чем выглядит терракота, и активность уже отдана цвету иконки. Значит внутри продукта её добирать нельзя.

Практически: воздуха больше, акцентов меньше. Ревизия макетов под это правило —

- заголовок экрана и заметки — без цвета, только вес и размер;
- **чипы тегов теряют заливку**: текст `--accent` на прозрачном фоне, разделитель точкой; заливка `--accent-soft` остаётся только у активного фильтра;
- маркеры списков и таймкоды — `--text-tertiary`, не акцент;
- акцент на экране — не более двух пятен: главное действие и текущее состояние;
- подсветка `==текст==` — `--amber-soft`, не акцентная.
