# Android adaptive icons

> Файл из пакета дизайн-системы СИМПАС (11.09.2026), положен в репозиторий как есть —
> правится только у источника. В ЗАПИСКАХ слои собирает `scripts/gen-icons.mjs`,
> а крупность в готовых файлах меряет `scripts/check-icon-scale.mjs`.

Канва **108×108 dp**. Маска лаунчера вырезает **центральные 72 dp** и растягивает их на всю плитку — внешние 18 dp с каждой стороны не видно никогда, они запас на параллакс.

Крупность считается от видимой зоны 72 dp, не от канвы: **высота дерева 43,2 dp** = 0,60 × 72, `scale(0.139355)` к исходному пути 500×500. Это то же соотношение, что на плоской плитке, — единое правило всей системы, см. [`ICON-SPEC.md`](ICON-SPEC.md). Внутри безопасного круга 66 dp дерево лежит с запасом и переживает любую маску OEM (круг, squircle, скруглённый квадрат, teardrop).

`*-preview.svg` кропнут по центральным 72 dp — то, что реально увидит пользователь. Превью на всю канву 108 dp показывает дерево на треть мельче правды; для приёмки не годится.

## Файлы на каждый сервис

| Файл | Слой | Куда |
| --- | --- | --- |
| `<сервис>-bg.svg` | background | `ic_launcher_background` — сплошная плашка цвета сервиса |
| `<сервис>-fg.svg` | foreground | `ic_launcher_foreground` — дерево в цвете сервиса, прозрачный фон |
| `<сервис>-mono.svg` | monochrome | `ic_launcher_monochrome` — дерево чёрным для themed icons (Android 13+); система сама перекрасит под обои |
| `<сервис>-preview.svg` | — | только для показа: как выглядит под squircle-маской. В сборку не кладётся |

## Сборка

```xml
<!-- res/mipmap-anydpi-v26/ic_launcher.xml -->
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@drawable/ic_launcher_background" />
    <foreground android:drawable="@drawable/ic_launcher_foreground" />
    <monochrome android:drawable="@drawable/ic_launcher_monochrome" />
</adaptive-icon>
```

SVG конвертируются в vector drawable через Android Studio (Asset Studio → Vector Asset) или `svg2vectordrawable`. Legacy-растр для API < 26 генерируется из `packages/ui/src/assets/services/<сервис>.svg`.

## Правила

- **Фон — только плашка.** Ни градиентов, ни теней, ни бликов: система накладывает собственные эффекты параллакса и тени при движении.
- **Крупность не менять.** 43,2 dp по высоте, центр 54 · 54. Слои сдвигаются относительно друг друга при параллаксе, и всё, что ближе к краю, срежется.
- **Углы не скруглять.** Маску даёт лаунчер; своё скругление поверх системного даёт двойной контур.
- **Контур дерева не менять.** Ни для одного сервиса, ни ради «оптической компенсации».
- **Monochrome — сплошной чёрный.** Никаких полутонов и прозрачности внутри силуэта: система работает с ним как с маской.
- **Надписей внутри иконки нет.** Имя сервиса рисует лаунчер.
