## Принятые допущения (вопросы остались без ответа)
- **Палитра — по мастер-ТЗ 2.0**, не по пакету: «Бумага · Гранат», 3 акцента,
  Golos Text. Пакет местами всё ещё исходит из отменённого DS-ALIGNMENT
  (6 акцентов, Geist, темы «Крем» и «Мел»). ITERATION-1 главнее во всём
  остальном — поведение и новые функции от палитры не зависят, цвета везде
  токенами. Темы «Крем» и «Мел» НЕ ввожу: значений для них нет, а изобретать
  запрещено правилом пакета.
- **Вложения в зашифрованной заметке** — не в этой итерации. §5 целиком для
  обычных заметок; в зашифрованной кнопка объясняет, почему пока нельзя.
  Контейнер остаётся версии 2.

## Изменения

### §2 Локализация — русский независимо от ОС
- `packages/core/src/i18n/i18n.ts:24` — `resolveLocale` больше не выбирает по ОС.
- `apps/web/src/main.tsx:52`, `apps/desktop/src/platform/strings.ts:83` — убрать
  ветку `navigator.languages`.
- `packages/app/src/state/store.ts:378` — `boot()` читает `PREF.locale`
  (сейчас `setLocale` пишет ключ, а не читает никто → выбор не переживает
  перезапуск).
- `packages/core/test/i18n.test.ts:110` — тест кодирует старое правило, переписать.

### §1 Заголовок — отдельное поле
- Модель: заголовок = первая строка `# …`, тело — со следующей непустой.
- `packages/app/src/screens/NoteScreen.tsx` — поле над телом; Enter/Tab/Backspace.
- `packages/app/src/components/NoteRow.tsx` — сниппет из тела, пустой → «Без названия».

### §3 Настройки — включить всё объявленное
- `packages/app/src/screens/SettingsScreen.tsx` + `state/store.ts` — аудит каждой
  строки; ширина колонки как главный пример. Неподключаемое — убрать.

### §7 теги · §9 мелочи · §6 строка заголовка Windows · §4 панель · §5 вложения · §8 два режима
Порядок работ — из `ITERATION-1.md` «Порядок работ».

### Инженерные баги (в пакете их нет)
- Android: safe-area (`apps/mobile`), не открываются настройки, рамка в редакторе.
- Windows: зависание Encrypt (Argon2id в основном потоке), отпечаток по факту.
- Сервер: redirect URI Яндекса.
- Темы сайта и приложения из одного `design/tokens.json`.
